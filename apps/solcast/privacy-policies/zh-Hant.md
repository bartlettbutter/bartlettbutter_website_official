**生效日期：** 2026年7月8日

Solcast（"本應用"）是一款適用於iPhone和iPad的免費天氣與生活方式指導應用。隱私是我們構建它的核心。本政策準確說明您使用Solcast時涉及哪些資料，更重要的是，不涉及哪些資料。

## 簡要版本

| 問題 | 回答 |
|------|------|
| 你們收集個人資料嗎？ | 否 |
| 我的位置會儲存在你們的伺服器上嗎？ | 否 |
| 有賬戶或登入嗎？ | 否 |
| 有追蹤或分析嗎？ | 否 |
| 有廣告嗎？ | 否 |
| 我的資料會被出售或共享嗎？ | 否 |
| 該應用對兒童安全嗎？ | 是 |

您的位置僅用於請求天氣資料，永遠不會儲存在我們控制的任何伺服器上。所有推薦都在您的裝置上計算。

## 收集哪些資料

**無。** Solcast沒有使用者賬戶、沒有分析平臺、沒有廣告SDK，也沒有任何形式的追蹤機制。我們不收集、儲存或傳輸個人資訊。

## 應用如何在本地使用資料

### 位置

當您授予位置許可權時，您的座標會傳送到天氣服務（如下所列）以檢索您所在區域的預報。您的位置永遠不會儲存在我們的伺服器上。

您新增的已儲存位置僅儲存在您的裝置上，除了作為天氣資料請求中的座標外，不會傳輸到任何地方。

### 偏好設定

您的個性化設定（溫度單位、敏感度級別、著裝風格、家庭選項）儲存在您的裝置本地。它們永遠不會離開您的裝置。

### 裝置端處理

所有生活方式指數、著裝推薦和每日簡報都完全在您的裝置上計算。不會向任何外部伺服器傳送任何偏好設定、結果或個人資料進行處理。

### 臨時快取

本應用保留一份短期的、記憶體中的天氣資料快取，以便您可以在已儲存的位置之間切換而無需等待重新下載。此快取僅存在於裝置記憶體中，永遠不會寫入持久儲存，並在應用關閉時清除。

## 許可權

Solcast請求一項許可權：

| 許可權 | 目的 |
|------|------|
| **位置（使用時）** | 獲取您當前位置的天氣、空氣質量和花粉資料 |

不請求其他許可權：相機、通訊錄、麥克風、通知、追蹤或任何其他許可權均不請求。

## 第三方服務

本應用連線以下服務以獲取天氣和環境資料：

| 服務 | 提供內容 | 傳送的資料 |
|------|---------|-----------|
| [Apple天氣](https://www.apple.com/legal/privacy/) | 天氣預報和狀況 | 僅地理座標 |
| 第三方天氣與環境服務 | 補充預報、空氣質量、花粉 | 僅地理座標 |
| [Apple地圖](https://www.apple.com/legal/privacy/) | 位置搜尋和城市名稱顯示 | 僅搜尋查詢或座標 |
| 公共假日服務 | 公共假日檢測 | 僅國家程式碼（例如"US"） |

**永遠不會向這些服務傳送任何個人資料、裝置識別符號、廣告ID或使用者偏好設定。**

## 資料共享

我們不向任何人出售、出租、許可或共享您的資料。本應用產生的唯一網路流量是從上述服務獲取天氣資料（座標）和假日資料（國家程式碼）。

## 資料保留和刪除

我們不在伺服器上儲存任何資料，因此沒有需要保留或刪除的內容。您裝置上的所有資訊（偏好設定、已儲存位置、快取的天氣）在您刪除應用的那一刻即被移除。

## 您的權利

由於我們不收集任何內容，因此我們這邊沒有個人資料可供訪問、更正、遷移或刪除。您透過管理或移除應用來對本地儲存的一切保持完全控制。

## 兒童隱私

Solcast不從任何人收集資訊，包括13歲以下的兒童（或您所在司法管轄區適用的年齡）。由於不收集個人資料，本應用對所有年齡的使用者都是安全的。

## 國際使用者

由於Solcast不收集個人資料，因此不會發生個人資訊的跨境傳輸。天氣和假日請求僅包含地理座標或國家程式碼。無論您身處何地，都不包含任何個人資料或裝置識別符號。

## 本政策的變更

如果我們更新此政策，修訂版本將在此處釋出，並附有新的生效日期。更新後繼續使用該應用即表示接受修訂後的政策。
