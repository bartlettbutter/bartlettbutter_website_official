# 我们随时为您提供帮助。

无论您是在设置第一次行程还是排查某个功能，都能在下面找到答案。如果找不到，请联系我们 — 我们乐意协助。

## 入门

### Journeyfolio免费吗？

是的。Journeyfolio免费下载，让您免费规划多达10段行程。高级功能 — 无限行程、实时航班跟踪和天气预报 — 通过可选的自动续订订阅（月度、6个月或年度）提供。

### 我在应用免费之前购买了它。我会失去访问权限吗？

不会。如果您在定价变更之前购买了应用，您将保留永久的高级访问权限，无需额外费用。您那边无需任何更改。

### 我需要创建账户吗？

不需要。没有注册、没有登录，也没有账户需要管理。打开应用即可立即开始规划。

### 我的行程数据存储在哪里？

所有数据都存储在您的设备本地。不会上传到外部服务器。没有云同步或备份。

### 如果我删除应用会怎样？

卸载Journeyfolio会永久移除所有存储的行程数据。由于没有云备份，此操作无法撤销。

### Journeyfolio可以在iPad上使用吗？

可以。应用针对iPad完全优化，具有自适应布局和多任务支持，包括分屏浏览和侧拉。

## 使用Journeyfolio

### 我可以规划包含多个城市的行程吗？

可以。将多个目的地添加到单次行程中。每个城市都有自己的行程板块、天气预报、日期范围和公共假日。

### 我可以添加哪些类型的活动？

七大类别涵盖您所需的一切：

- **航班** — 航班号、座位、确认单、实时状态
- **酒店** — 地址、电话、入住/退房日期、备注
- **交通** — 租车、火车、公交、渡轮、拼车、班车
- **餐厅** — 名称、地址、电话、备注
- **地点和门票** — 景点、博物馆、活动、旅游、公园、购物
- **保险** — 保单详情和备注
- **其他** — 任何其他值得记住的事项

### 一项活动可以跨越多天吗？

可以。添加活动时切换"多天"以设置开始和结束日期。它将出现在其涵盖的每一天。

### 如何将文档附加到活动？

打开任何活动，点击附件选项，然后用相机拍摄照片或导入文件。支持的格式包括PDF、JPEG和PNG。智能OCR将尝试从您的文档中自动填写预订详情。

### 位置搜索如何运作？

添加活动时，在内置搜索中输入名称或关键词。点击结果即可自动填写详情并查看地图预览。

### 天气预报如何运作？

添加目的地城市，Journeyfolio就会通过[Apple天气](https://weatherkit.apple.com/legal-attribution.html)获取当前状况和5天预报。在天气卡片上切换°C和°F。*天气预报需要高级订阅。*

### 航班跟踪如何运作？

输入您的航班号和出发日期，然后点击"验证航班"。应用会以每个机场的当地时区自动填写航线、航空公司和时间。对于约24小时内的出发，实时状态标识（准时、延误、取消、飞行中、已降落）会自动出现。*实时航班跟踪需要高级订阅。*

时刻表验证涵盖未来12个月和过去3个月的航班。

### 公共假日如何运作？

Journeyfolio会检测您目的地的国家，并在日期条中显示公共假日。假日日期以柔和的黄色背景突出显示，以便您围绕闭店安排计划。

### 我需要互联网连接吗？

您的行程数据始终可离线访问。只有天气预报、航班验证/状态、公共假日信息和位置搜索才需要互联网连接。

### 如何置顶或删除行程？

在行程上向右滑动可将其置顶到列表顶部。向左滑动可删除。任何删除操作前都会出现确认提示。

## 订阅管理

### 如何升级到高级版？

打开应用并按照应用内升级提示操作。您可以选择月度、6个月或年度套餐。

### 如何取消或更改我的订阅？

在您的设备上前往**设置 → Apple ID → 订阅**。您可以随时切换套餐或取消。高级访问权限会在您当前计费周期结束前保持有效。

### 如果我取消，会丢失我的行程吗？

不会。您的行程数据存储在本地，完全独立于您的订阅。取消高级版仅限制对航班跟踪和天气功能的访问。

## 疑难解答

### 天气预报无法加载

1. 确认您的设备已连接互联网。
2. 验证目的地城市名称是否正确。
3. 确保您拥有有效的高级订阅。
4. 如果仍然无法加载，请几分钟后重试 — 天气服务可能暂时不可用。

### 航班验证显示"未找到航班"

- 仔细检查航班号格式（例如"JL001"或"AA100"）。
- 确认出发日期正确。
- 注意：验证涵盖过去3个月至未来12个月。一些区域性或包机航班可能不可用。

### 航班状态未显示

实时状态标识仅在航班出发前约24小时内出现。更远期的航班仍会显示已验证的时刻表信息。实时跟踪需要高级订阅。

### 位置搜索未返回结果

请确保您已连接互联网，并尝试更具体的词语（例如"东京希尔顿"而非"酒店"）。

### 公共假日未显示

假日需要为您的目的地识别出国家。尝试更具体的城市名称（例如"法国巴黎"而非"巴黎"）。

### 文档附加功能无法使用

- 如出现提示，请授予相机权限（设置 → Journeyfolio → 相机）。
- 对于导入，请确保文件为PDF、JPEG或PNG。
- 重启应用并重试。

### 我的行程数据似乎丢失了

行程数据在应用更新期间会被保留。尝试重启应用或您的设备。注意：卸载应用会永久移除所有数据，因为没有云备份。如果重启后数据仍然丢失，请联系我们。

### 应用崩溃或行为异常

1. 从App Store更新到最新版本。
2. 重启应用和您的设备。
3. 如果问题持续，请通过详情邮件联系我们（见下方）。
