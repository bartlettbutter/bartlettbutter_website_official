**発効日：** 2026年10月28日

LinkHQ（以下「本アプリ」）は、すべてをデバイスの中に保つ、iPhone と iPad 向けの無料のリンクライブラリです。プライバシーは本アプリの設計の中心にあります。このポリシーでは、LinkHQ の利用時にどのデータが関わるのか、そしてより大切な、どのデータが関わらないのかを正確に説明します。

## 短い要約

| 質問 | 回答 |
|----------|--------|
| 個人データを収集しますか？ | いいえ |
| ライブラリがサーバーに送られますか？ | いいえ |
| アカウントやログインはありますか？ | いいえ |
| 追跡や分析はありますか？ | いいえ |
| 広告はありますか？ | いいえ |
| データが販売・共有されますか？ | いいえ |
| 子どものデータを収集しますか？ | いいえ |

保存したリンクと、そのタイトル、メモ、タグ、キーワード、カテゴリは、すべてデバイスにとどまります。私たちはあなたのデータを受け取るサーバーを運営していません。LinkHQ がネットワークを使うのは、以下に説明するとおり、保存したリンクの情報を調べるときだけです。

## どのデータが集められるか

**ありません。** LinkHQ にはユーザーアカウント、分析プラットフォーム、広告 SDK、いかなる追跡の仕組みもありません。個人情報を収集、保存、送信することはありません。

## アプリがデータをローカルで使う方法

### 保存したリンク

保存したリンクと、そのタイトル、メモ、タグ、キーワード、カテゴリ、ソース、お気に入り、開封状態と閲覧可否の状態は、本アプリと共有シート用の拡張機能が共有するコンテナに入れて、デバイスにのみ保存されます。アップロードされることはありません。

### 共有シートからの保存

LinkHQ に何かを共有すると、本アプリは保存のために、共有されたリンク、または共有テキスト内のリンクを読み取ります。これはデバイス上で行われます。共有の内容が私たちの管理するサーバーに送られることはありません。

### デバイス上のキーワード

リンクを保存すると、検索と絞り込みのために、内容を表すいくつかのキーワードがデバイス上で選ばれます。これにはデバイス上の Apple の言語フレームワークを使います。そのためにテキストがどこかへ送られることはありません。

### デバイス上のトピック振り分け

LinkHQ は各リンクを、フードや旅行などのトピックに振り分けます。Apple Intelligence がオンのデバイスではデバイス上の Apple の基盤モデルを使い、そうでない場合はリンクのタイトル、タグ、キーワード、メモをもとに LinkHQ が振り分けます。どちらも完全にデバイス上で動作し、そのためにリンクの情報がどこかへ送られることはありません。

### プレビュー画像

プレビュー画像は、表示のたびに再ダウンロードしなくて済むよう、デバイスにキャッシュされます。このキャッシュは iOS が管理し、本アプリと一緒に削除されます。

### 設定と評価のお願い

外観の選択（System、Light、Dark）はデバイスに保存されます。頻繁にお願いしすぎないよう、LinkHQ は最後に評価をお願いした日時と、Settings から App Store のレビューページを開いたかどうかを、小さな記録としてローカルに残します。評価とレビューは私たちではなく Apple の App Store が扱います。この記録がデバイスの外に出ることはありません。

## LinkHQ のネットワークの使い方

ただの URL ではなく本当のタイトルとプレビュー画像を表示し、リンクのコンテンツが削除されたときにお知らせするために、LinkHQ は保存したリンクの情報を調べます。どの問い合わせも 1 つのリンクについてだけで、コレクション全体に関わることはありません。

- **タイトル、プレビュー、キーワード。** リンクを保存したとき、また完了しなかった場合はあとでアプリ内で、LinkHQ はリンクを**そのリンク自身のサイト**に求めます。一部のプラットフォームでは、代わりにそのプラットフォームの**公開されている埋め込み・データサービス**（たとえば YouTube、TikTok、X、Bilibili、Wikipedia）に問い合わせます。これはほかの Web サイトに埋め込まれた投稿を表示しているのと同じ情報源です。短縮リンク（bit.ly など）は、行き先を知るために発行元のサービスをたどります。
- **プレビュー画像**は、リンク先のサイトが示す場所から読み込まれます。そのサイトの画像サーバーの場合もあります。
- **閲覧可否の確認。** ライブラリを開くたびに、LinkHQ は同じ方法で各リンクのサイト、またはそのプラットフォームの公開サービスに問い合わせ、保存したリンクがまだ閲覧できるかを確認します。Check Again で 1 つのリンクだけを確認することもできます。
- これらのリクエストは、ブラウザがそのリンクに対して行うのと同じものとして、デバイスから直接送られます。私たちが運営するサーバーには送られず、アカウントや個人を識別する情報も含みません。そうしたものが存在しないからです。
- **ライブラリはアップロードされません。** メモ、タグ、キーワード、カテゴリ、お気に入りがどこかへ送られることはありません。

オフライン時など、サイトに届かなかった問い合わせは、のちの起動時に改めて試されるだけです。

## 権限

LinkHQ はデバイスの機微な権限を求めません。

| 権限 | 状態 |
|------------|--------|
| **マイク** | 要求しない |
| **カメラ** | 要求しない |
| **連絡先** | 要求しない |
| **写真** | 要求しない |
| **ヘルスケアデータ** | 要求しない |
| **位置情報** | 要求しない |

共有シートからのリンク保存と、元の場所での開き直しに、これらの権限は一切必要ありません。

## 第三者サービス

LinkHQ は第三者の分析、広告、追跡サービスを組み込んでいません。リンクの問い合わせは、各リンクのサイト、またはそのプラットフォームの公開サービスに直接行われます。キーワードとトピック振り分けには、デバイスのオペレーティングシステムの一部として動作する Apple のフレームワークを使います。Open Original を含め、LinkHQ から移動した先の Web サイトには、それぞれのプライバシーポリシーがあります。

## データの共有

私たちはあなたのデータを誰にも販売、貸与、ライセンス、共有しません。LinkHQ がライブラリ、メモ、タグ、キーワード、カテゴリを送信することはありません。

## データの保持と削除

私たちはサーバーにデータを保存しないため、こちら側で保持・削除するものはありません。デバイス上のすべて、つまり保存したリンクとその詳細は、本アプリを削除した時点で消去されます。Settings › Delete All Links でライブラリをその場で空にすることもできます。

## あなたの権利

私たちは何も収集しないため、こちら側に閲覧、訂正、移転、消去の対象となる個人データはありません。本アプリを管理または削除することで、ローカルに保存されたすべてを完全にコントロールできます。

## 子どものプライバシー

LinkHQ は、13 歳未満（またはお住まいの地域で定められた年齢未満）の子どもを含め、誰からも情報を収集しません。LinkHQ は保存したリンクのサイトからタイトルとプレビューを表示するため、目にするコンテンツは、残すことにしたリンクによって決まります。

## 国際的な利用者

LinkHQ は個人データを収集しないため、個人情報の国境を越えた移転は発生しません。リンクの問い合わせは、保存したリンクをホストしているサイトに届きます。

## このポリシーの変更

このポリシーを更新した場合は、改訂版を新しい発効日とともにここに掲載します。更新後も本アプリを使い続けることで、改訂版のポリシーに同意したものとみなされます。
