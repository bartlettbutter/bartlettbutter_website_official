**生效日期：** 2026年10月28日

LinkHQ（“本应用”）是一款适用于 iPhone 和 iPad 的免费链接收藏库，所有内容都留在你的设备上。隐私是我们打造它的核心。本政策会准确说明你使用 LinkHQ 时涉及哪些数据，以及更重要的，不涉及哪些数据。

## 简要版

| 问题 | 回答 |
|----------|--------|
| 你们会收集个人数据吗？ | 否 |
| 我的收藏会发送到你们的服务器吗？ | 否 |
| 有账户或登录吗？ | 否 |
| 有追踪或分析吗？ | 否 |
| 有广告吗？ | 否 |
| 我的数据会被出售或共享吗？ | 否 |
| 你们会收集儿童的数据吗？ | 否 |

你保存的链接，以及它们的标题、备注、标签、关键词和类别，全都留在你的设备上。我们不运营任何接收你数据的服务器。LinkHQ 只在查询你保存的链接时使用网络，具体如下所述。

## 收集了哪些数据

**没有。** LinkHQ 没有用户账户、没有分析平台、没有广告 SDK，也没有任何形式的追踪机制。我们不收集、不存储、也不传输任何个人信息。

## 应用如何在本地使用数据

### 你保存的链接

你保存的链接，以及它们的标题、备注、标签、关键词、类别、来源、收藏、打开状态和可访问状态，只存储在你的设备上，放在本应用与其共享菜单扩展共用的容器中。它们绝不会被上传。

### 从共享菜单保存

当你把内容分享到 LinkHQ 时，本应用会读取分享的链接，或分享文字中的链接，以便保存。这一过程在你的设备上进行。与这次分享有关的任何内容都不会发送到我们控制的服务器。

### 设备端关键词

保存链接时，会在你的设备上挑选几个描述其内容的关键词，用于搜索和筛选。这一过程使用 Apple 的设备端语言框架，不会为此把任何文字发送到任何地方。

### 设备端主题归类

LinkHQ 会把每条链接归入一个主题，比如美食或旅行。在开启了 Apple 智能的设备上，这会使用 Apple 的设备端基础模型；否则，LinkHQ 会根据链接的标题、标签、关键词和备注归类。两种方式都完全在你的设备上运行，不会为此把任何与你的链接有关的内容发送到任何地方。

### 预览图

预览图会缓存在你的设备上，这样每次显示时就不必重新下载。缓存由 iOS 管理，并会随应用一起删除。

### 设置与评分请求

你选择的外观（System、Light 或 Dark）存储在你的设备上。为了不过于频繁地打扰你，LinkHQ 还会在本地保留一条简短记录，记下上次请你为应用评分的时间，以及你是否从 Settings 打开过 App Store 的评论页面。评分和评论由 Apple 的 App Store 处理，而不是我们。这条记录从不离开你的设备。

## LinkHQ 如何使用网络

为了显示链接真正的标题和预览图，而不是一串网址，并在链接内容被删除时告诉你，LinkHQ 会查询你保存的链接。每次查询只涉及一条链接，绝不涉及你的整个收藏。

- **标题、预览图和关键词。** 保存链接时，以及在未完成的情况下稍后在应用中，LinkHQ 会向**链接所在的网站**请求该链接。对某些平台，它会改为询问该平台的**公开嵌入或数据服务**（例如 YouTube、TikTok、X、哔哩哔哩或维基百科），也就是为其他网站上的嵌入帖子提供内容的同一来源。短链接（如 bit.ly）会经由签发它的服务进行跳转，以确定它指向哪里。
- **预览图**从链接所在网站指向的位置加载，可能是该网站的图片服务器。
- **可访问性检查。** 打开收藏库时，LinkHQ 会以同样的方式询问每条链接所在的网站或该平台的公开服务，检查你保存的链接是否仍可访问。每条链接最多每 12 小时检查一次。你也可以用 Check Again 检查单条链接。
- 这些请求直接从你的设备发出，和你的浏览器访问该链接时发出的请求一样。它们不会发送到我们运营的任何服务器，也不带有任何账户或个人标识，因为根本不存在这些信息。
- **你的收藏绝不会被上传。** 你的备注、标签、关键词、类别和收藏都不会被发送到任何地方。

无法连接到网站的查询（例如离线时）只会在之后启动应用时重试。

## 权限

LinkHQ 不请求任何敏感的设备权限。

| 权限 | 状态 |
|------------|--------|
| **麦克风** | 未请求 |
| **相机** | 未请求 |
| **通讯录** | 未请求 |
| **照片** | 未请求 |
| **健康数据** | 未请求 |
| **位置** | 未请求 |

从共享菜单保存链接、在来源处重新打开链接，都不需要上述任何权限。

## 第三方服务

LinkHQ 不集成任何第三方分析、广告或追踪服务。链接查询会直接联系每条链接所在的网站或该平台的公开服务。关键词和主题归类使用作为操作系统一部分在你的设备上运行的 Apple 框架。你通过 LinkHQ（包括通过 Open Original）访问的网站有各自的隐私政策。

## 数据共享

我们不会向任何人出售、出租、授权或共享你的数据。LinkHQ 从不传输你的收藏、备注、标签、关键词或类别。

## 数据保留与删除

我们不在服务器上存储任何数据，所以在我们这边没有需要保留或删除的内容。你设备上的一切，包括保存的链接及其所有详情，会在你删除应用时一并删除。你也可以通过 Settings › Delete All Links 直接清空收藏库。

## 你的权利

由于我们不收集任何东西，我们这边没有可供访问、更正、转移或删除的个人数据。通过管理或删除应用，你可以完全掌控本地存储的一切。

## 儿童隐私

LinkHQ 不向任何人收集信息，包括 13 岁以下（或你所在司法辖区规定年龄以下）的儿童。LinkHQ 会显示来自你所保存链接网站的标题和预览图，因此你看到的内容取决于你选择保留的链接。

## 国际用户

由于 LinkHQ 不收集个人数据，因此不存在个人信息的跨境传输。链接查询会到达托管你所保存链接的网站。

## 本政策的变更

如果我们更新本政策，修订后的版本会连同新的生效日期发布在此。更新后继续使用本应用，即表示你接受修订后的政策。
