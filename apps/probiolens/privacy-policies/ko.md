**시행일:** 2026년 10월 14일

ProbioLens는 Bartlett Butter LLC(“당사”)가 발행합니다. ProbioLens는 보충제 영양정보 라벨을 기기에서 직접 스캔하고 해석해 이해를 돕습니다. 당사는 개인정보 보호를 최우선으로 설계했습니다. 필요하지 않기에 당사는 여러분의 데이터를 수집하지 않습니다.

## 요약

| 질문 | 답변 |
|------|------|
| 개인정보를 수집하나요? | 아니요 |
| 제 사진이 기기를 벗어나나요? | 아니요 |
| 계정이나 로그인이 있나요? | 아니요 |
| 추적이나 분석이 있나요? | 아니요 |
| 광고가 있나요? | 아니요 |
| 제 데이터가 판매되거나 공유되나요? | 아니요 |
| 앱이 어린이에게 안전한가요? | 예 |

ProbioLens는 어떤 개인정보도 수집, 전송, 판매 또는 공유하지 않습니다. 앱이 하는 모든 일은 여러분의 기기에서 이루어집니다.

## 기기에 남는 것

ProbioLens는 다음을 기기에만 저장하며, 그 어느 것도 당사나 타인에게 보내지 않습니다:

- 촬영하거나 선택한 **라벨 사진**은 Apple의 기기 내 텍스트 인식으로 기기에서 읽힙니다. 스캔과 함께 저장한 사진은 앱의 비공개 저장소에 보관되며, 저장하지 않은 스캔의 사진은 다음에 앱을 열 때 삭제됩니다.
- **스캔 결과와 기록**. 수정한 내용과 입력한 가격을 포함합니다.
- 입력을 선택한 경우의 **목표와 개인 세부정보**(예: 쇼핑 목표, 연령대, 임신 또는 수유, 면역 상태, 식이 회피). 선택 사항이며 앱 내 메모를 표시하는 데만 사용됩니다.
- **앱 설정.**

이 정보를 받는 서버가 당사에는 없으며, 앱은 완전히 오프라인으로 작동합니다.

## 분석 방식

모든 처리는 로컬입니다:

- **텍스트 인식**: Apple의 내장 Vision 프레임워크로 기기에서.
- **해석**: 라벨 사실을 앱에 포함된 참고 라이브러리와 대조합니다.
- **비교 및 비용 계산**: 기기에서 계산됩니다.

인터넷 연결이 필요하지 않으며, 이 작업 중에 데이터가 기기를 벗어나지 않습니다.

## 당사가 하지 않는 것

- 계정이나 가입 없음.
- 분석, 광고, 추적 SDK 없음.
- 앱이나 웹사이트 간 추적 없음.
- 제3자에 대한 데이터 판매나 공유 없음.

## 카메라 및 사진 접근

앱은 보충제 영양정보 라벨을 촬영할 수 있도록 하기 위해서만 카메라 접근을 요청합니다. 대신 라이브러리에서 사진을 고를 수 있으며, 앱은 여러분이 선택한 사진만 받습니다.

## 권한

| 권한 | 목적 | 필수 여부 |
|------|------|-----------|
| 카메라 | 보충제 영양정보 라벨 촬영 | 선택 |
| 사진 라이브러리 | 라벨의 기존 사진 선택 | 선택 |

ProbioLens는 다음에 대한 접근을 **요청하지 않습니다**: 위치, 연락처, 마이크, 블루투스, 건강 데이터, App Tracking Transparency(ATT), 기타 민감한 시스템 권한.

## 데이터 보관 및 삭제

모든 데이터는 기기에만 존재합니다. 삭제하려면:

- **저장된 스캔**: 설정 → 스캔 기록 지우기.
- **내 목표**: 설정 → 내 목표.
- **모두**: 기기에서 ProbioLens를 삭제하세요.

## 여러분의 권리

당사는 서버에 개인정보를 보관하지 않으므로, 당사가 제공·정정·이전·삭제할 것이 없습니다. 기기에 로컬로 저장된 모든 것에 대한 완전한 소유권과 통제권은 여러분에게 있습니다.

## 어린이 개인정보

ProbioLens는 13세 미만 어린이를 대상으로 하지 않으며, 어린이를 포함해 누구로부터도 고의로 정보를 수집하지 않습니다. 앱은 어린이에게 안전하며, 관할 지역에서 적용되는 어린이 개인정보 보호 규정을 준수합니다.

## 의학적 조언이 아님

ProbioLens는 보충제 영양정보 라벨을 교육 목적으로만 해석합니다. 제품을 진단·치료·추천·순위 매기지 않으며, 전문적인 의학적 조언을 대신하지 않습니다.

## 국제 사용자

ProbioLens는 개인정보를 수집하지 않고 정상적인 사용 중 네트워크 요청을 하지 않으므로, 국경 간 데이터 이전이 발생하지 않습니다. 앱은 위치와 관계없이 동일하게 작동합니다.
