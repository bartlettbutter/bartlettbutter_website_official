**生效日期：** 2026年6月13日

Nekopedia（"本应用"）是一款免费的iOS应用程序，可通过照片识别猫的品种。您的隐私是我们构建此应用的核心理念。以下是您的信息被处理方式的详细说明。

## 简要版本

| 问题 | 回答 |
|------|------|
| 你们收集个人数据吗？ | 否 |
| 我的照片会离开我的设备吗？ | 否 |
| 有账户或登录吗？ | 否 |
| 有追踪或分析吗？ | 否 |
| 有广告吗？ | 否 |
| 我的数据会被出售或共享吗？ | 否 |
| 儿童可以安全使用该应用吗？ | 是 |

您的照片完全在您的设备上处理，永远不会离开设备。品种识别完全离线运行。本应用发出的唯一网络请求是获取品种信息、图片和游戏内容以供显示。

## 我们收集的数据

无。我们不收集、存储或传输任何个人数据。本应用不包含用户账户、分析SDK、广告框架或任何第三方追踪工具。

## 照片和相机/相册访问

本应用请求相机和照片库权限仅用于让您拍摄或选择猫的图片进行品种识别。您拍摄或选择的照片完全在您的设备上使用本地智能进行分析。您的照片永远不会上传到任何服务器。

## 本地存储的数据

您保存到收藏夹的品种扫描结果仅存储在您的设备上。这些数据永远不会对外传输，可以随时通过删除应用来移除。

## 第三方服务

本应用连接以下服务仅用于获取显示内容，如品种信息、图片和游戏数据：

| 服务 | 目的 | 发送的数据 | 隐私信息 |
|------|------|-----------|----------|
| The Cat API | 品种信息（性格、数据、历史）和测验照片 | 无 | [thecatapi.com](https://thecatapi.com) |
| catfact.ninja | 猫咪趣闻功能的猫咪事实 | 无 | [catfact.ninja](https://catfact.ninja) |

这些是标准的内容获取请求。不包含任何个人数据、设备标识符或追踪信息。

## 数据共享

我们不向第三方出售、出租或共享任何用户数据。没有数据可供共享。

## 权限

| 权限 | 我们为什么请求 | 是否必需？ |
|------|--------------|-----------|
| 相机 | 拍摄猫的照片以进行品种识别 | 可选（您可以使用照片库） |
| 照片库 | 选择现有照片以进行品种识别 | 可选（您可以使用相机） |

不请求或访问其他权限。本应用不使用位置、通讯录、麦克风、追踪、通知或任何其他敏感访问。

## 数据保留和删除

由于我们不在服务器上收集任何数据，因此我们这边没有需要保留或删除的内容。所有本地存储的数据，包括收藏夹和扫描历史，会在您从设备上删除应用时自动移除。

## 您的权利

由于Nekopedia不收集个人数据，我们的系统中没有用户数据可供访问、导出、更正或删除。您对设备上本地存储的所有数据保持完全控制。

## 儿童隐私

本应用不收集任何人的信息，包括13岁以下的儿童（或您所在司法管辖区适用的年龄）。由于不收集个人数据，本应用对所有年龄的用户都是安全的，并符合COPPA要求。

## 国际用户

由于Nekopedia不收集个人数据，因此不会发生个人信息的跨境传输。向第三方服务发出的内容获取请求（品种信息、图片、游戏内容）不包含任何个人数据或设备标识符，无论您身处何地。

## 本政策的变更

如果我们更新此政策，修订版本将在此页面发布，并附有更新的生效日期。更新后继续使用该应用即表示接受修订后的政策。
