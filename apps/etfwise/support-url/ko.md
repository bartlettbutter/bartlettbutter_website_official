# 무엇을 도와드릴까요?

저희는 여러분이 ETFWise를 최대한 활용하실 수 있도록 돕고자 합니다. 아래 답변을 둘러보시거나 필요한 것을 찾지 못하셨다면 직접 문의해 주세요.

## 시작하기

### 매일의 추천은 어떻게 작동하나요?

매일 ETFWise는 실시간 시장 데이터를 기반으로 일곱 개 카테고리(주요 지수, 섹터, 채권 및 고정 수익, 국제, 원자재, 테마, 배당)에 걸쳐 상위 ETF를 선정합니다. 목록은 하루 종일 고정되어 화면이 안정적으로 유지되며, 가격과 감성은 5분마다 자동으로 갱신됩니다. 하위 카테고리를 살펴보려면 아무 섹션에서 "더 보기"를 누르세요.

### API 키가 필요한가요?

무료 Finnhub API 키는 실시간 가격, 뉴스, 애널리스트 데이터를 잠금 해제합니다. [finnhub.io](https://finnhub.io) 에서 하나 얻어 첫 실행 시 입력할 수 있습니다. 이 단계를 건너뛰면 앱은 내장된 데모 데이터로 실행되어 전체 인터페이스를 살펴볼 수 있습니다.

### 인터넷 연결이 필요한가요?

예, 실시간 가격, 뉴스, 감성, 펀드 데이터에는 필요합니다. 강세 및 위험 시나리오 분석은 이미 화면에 표시된 데이터로부터 여러분의 기기에서 즉시 생성되므로 추가 연결이 필요하지 않습니다.

### ETFWise는 얼마인가요?

ETFWise는 App Store에서 무료로 다운로드할 수 있습니다. 구독이나 광고가 없습니다.

## 자주 묻는 질문

### 일곱 개의 ETF 카테고리는 무엇인가요?

| 카테고리 | 포함 내용 |
|---|---|
| 주요 지수 | S&P 500, 나스닥 100, 러셀 2000, 다우존스, 전체 시장 |
| 섹터 | 기술, 헬스케어, 에너지, 금융 등 |
| 채권 및 고정 수익 | 국채, 회사채, 고수익, TIPS, 지방채 |
| 국제 | 선진 시장, 신흥 시장, 단일 국가 ETF |
| 원자재 | 금, 은, 석유, 농업, 광범위한 원자재 바스켓 |
| 테마 | AI 및 로봇, 청정 에너지, 사이버 보안, 클라우드, 전기차 |
| 배당 | 고수익, 배당 성장, 귀족주, 인컴 전략 |

### 강세 및 위험 시나리오는 어떻게 생성되나요?

ETFWise는 각 강세 및 위험 시나리오를 해당 ETF에 대해 이미 표시된 실제 데이터(가격, 수익률, 감성, 보수율 등)로부터 여러분의 기기에서 구성합니다. 생성은 즉시 이루어지며, 다운로드나 계정이 필요하지 않고, 외부 서버로 전송되는 것은 없습니다.

### 뉴스 감성은 어떻게 작동하나요?

앱은 각 ETF에 대한 최근 뉴스 기사(7일 기간)를 분석하여 긍정적 또는 부정적 어조를 평가합니다. 결과는 약세, 부정적, 중립, 긍정적 또는 강세로 표시됩니다. 점수와 함께 최대 3개의 최신 헤드라인이 표시됩니다.

### 특정 ETF를 검색할 수 있나요?

예. 검색 창을 사용하여 티커 심볼이나 이름으로 어떤 ETF든 찾을 수 있습니다. 검색은 200개 이상의 엄선된 ETF와 총 400개 이상의 티커로 구성된 확장 라이브러리를 다룹니다.

### 제 데이터는 비공개인가요?

예. 계정 없음, 분석 없음, 추적 없음. 금융 데이터 제공업체로 전송되는 것은 티커 심볼뿐입니다. 자세한 내용은 전체 [개인정보 처리방침](https://www.bartlettbutter.com/etfwise/privacy/)을 참조하세요.

### 앱을 삭제하면 어떻게 되나요?

ETFWise를 제거하면 캐시된 추천, 생성된 분석, 여러분의 API 키를 포함하여 로컬에 저장된 모든 데이터가 영구적으로 제거됩니다. 클라우드 백업이 없으므로 이 작업은 되돌릴 수 없습니다.

## 문제 해결

### 가격이 로드되지 않아요

유효한 Finnhub API 키를 입력했는지([finnhub.io](https://finnhub.io) 에서 무료 발급) 확인하고 기기가 인터넷에 연결되어 있는지 확인하세요. API 키 단계를 건너뛰었다면 앱은 실시간 가격 대신 데모 데이터를 표시하며, 이는 예상된 동작입니다.

### "ETF 데이터를 로드할 수 없습니다" 오류

이는 대개 네트워크 요청이 실패했음을 의미합니다. 인터넷 연결을 확인하고 "다시 시도"를 누르세요. Finnhub API 키를 사용 중이라면 앱 설정에 올바르게 입력되어 있는지 확인하세요.

### 강세 및 위험 시나리오가 표시되지 않아요

강세 및 위험 시나리오는 ETF의 가격, 성과, 감성 데이터로부터 구성됩니다. 표시되지 않는다면 그 기반 데이터의 로딩이 아직 완료되지 않은 것입니다. 인터넷에 연결되어 있는지 확인한 후 ETF 상세 보기를 다시 열어 보세요.

### 펀드 데이터(보유 종목, 성과)가 로드되지 않아요

보유 종목 및 성과 데이터에는 인터넷 연결이 필요합니다. 데이터 로드에 실패하면 ETF 상세 보기를 닫았다가 다시 열어 보세요.

### 앱이 충돌하거나 멈춰요

App Store의 최신 버전을 실행하고 있는지 확인한 후 앱을 강제 종료했다가 다시 여세요. 문제가 계속되면 기기를 재시작하세요. 그래도 지속되면 아래로 문의해 주세요.
