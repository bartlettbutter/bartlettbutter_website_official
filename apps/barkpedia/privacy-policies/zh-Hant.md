**生效日期：** 2026年4月11日

Barkpedia（"本應用"）是一款免費的iOS應用程式，可透過照片識別狗的品種。您的隱私是我們構建此應用的核心理念。以下是您的資訊被處理方式的詳細說明。

## 簡要版本

| 問題 | 回答 |
|------|------|
| 你們收集個人資料嗎？ | 否 |
| 我的照片會離開我的裝置嗎？ | 否 |
| 有賬戶或登入嗎？ | 否 |
| 有追蹤或分析嗎？ | 否 |
| 有廣告嗎？ | 否 |
| 我的資料會被出售或共享嗎？ | 否 |
| 兒童可以安全使用該應用嗎？ | 是 |

## 我們收集的資料

**無。** 我們不收集、儲存或傳輸任何個人資料。本應用不包含使用者賬戶、分析SDK、廣告框架或任何第三方追蹤工具。

## 您的照片如何被處理

本應用請求相機和照片庫許可權僅用於讓您拍攝或選擇狗的圖片進行品種識別。您拍攝或選擇的照片完全在您的裝置上使用本地智慧進行分析。**您的照片永遠不會上傳到任何伺服器。**

## 裝置上儲存的內容

- **收藏夾** — 您選擇儲存的品種掃描結果僅儲存在您的裝置本地。
- **探索資料** — 品種搜尋索引和原產國地圖資料已捆綁在應用本身內。
- **地圖渲染** — 互動式世界地圖使用Apple地圖（MapKit），完全在您的裝置上本地渲染。

這些資料均不會對外傳輸。當您刪除應用時，所有這些資料都會自動移除。

## 網路請求

本應用連線第三方狗品種參考服務僅用於獲取顯示內容：品種資料（性格、資料、歷史）、品種圖片和測驗照片。這些是標準的內容獲取請求。

**任何請求中都不包含個人資料、裝置識別符號或追蹤資訊。** 沒有任何請求會識別您的身份，也永遠不會傳輸任何分析或廣告資料。

## 資料共享

我們不向第三方出售、出租或共享任何使用者資料。沒有使用者資料可供共享。

## 我們請求的許可權

| 許可權 | 我們為什麼請求 | 是否必需？ |
|------|--------------|-----------|
| 相機 | 拍攝狗的照片以進行品種識別 | 可選 — 您可以使用照片庫 |
| 照片庫 | 選擇現有照片以進行品種識別 | 可選 — 您可以使用相機 |

**僅此而已。** 本應用不請求或訪問位置、通訊錄、麥克風、藍芽、追蹤（ATT）、通知或任何其他敏感許可權。

## 資料保留和刪除

由於我們不在伺服器上收集任何資料，因此我們這邊沒有需要保留或刪除的內容。所有本地儲存的資料，包括收藏夾和掃描歷史，會在您從裝置上刪除應用時自動移除。

## 您的權利

由於Barkpedia不收集個人資料，我們的系統中沒有使用者資料可供訪問、匯出、更正或刪除。您對裝置上本地儲存的一切保持完全控制。

## 兒童隱私

本應用不收集任何人的資訊，包括13歲以下的兒童（或您所在司法管轄區適用的年齡）。由於不收集個人資料，本應用對所有年齡的使用者都是安全的，並符合COPPA要求。

## 國際使用者

由於Barkpedia不收集個人資料，因此不會發生個人資訊的跨境傳輸。向第三方服務發出的內容獲取請求（品種資訊、圖片）不包含任何個人資料或裝置識別符號，無論您身處何地。

## 本政策的變更

如果我們更新此政策，修訂版本將在此頁面釋出，並附有更新的生效日期。更新後繼續使用該應用即表示接受修訂後的政策。
