**Fecha de vigencia:** 13 de junio de 2026

Nekopedia ("la Aplicación") es una aplicación iOS gratuita que identifica razas de gatos a partir de fotos. Tu privacidad es fundamental en el diseño de esta aplicación. Aquí explicamos exactamente cómo se maneja tu información.

## Versión Resumida

| Pregunta | Respuesta |
|----------|-----------|
| ¿Recopilan datos personales? | No |
| ¿Mis fotos salen de mi dispositivo? | No |
| ¿Hay cuentas o inicios de sesión? | No |
| ¿Hay rastreo o analíticas? | No |
| ¿Hay anuncios? | No |
| ¿Se venden o comparten mis datos? | No |
| ¿Los niños pueden usar la aplicación de forma segura? | Sí |

Tus fotos se procesan completamente en tu dispositivo y nunca salen de él. La identificación de razas funciona completamente sin conexión. Las únicas solicitudes de red que realiza la Aplicación son para obtener información sobre razas, imágenes y contenido de juegos para su visualización.

## Datos que Recopilamos

Ninguno. No recopilamos, almacenamos ni transmitimos ningún dato personal. La Aplicación no contiene cuentas de usuario, SDKs de analíticas, frameworks publicitarios ni herramientas de rastreo de terceros.

## Fotos y Acceso a la Cámara/Biblioteca

La Aplicación solicita permisos de cámara y biblioteca de fotos únicamente para permitirte fotografiar o seleccionar imágenes de gatos para la identificación de raza. Las fotos que tomas o seleccionas se analizan completamente en tu dispositivo utilizando inteligencia en el dispositivo. Tus fotos nunca se suben a ningún servidor.

## Datos Almacenados Localmente

Los resultados de escaneo de razas que guardas en Favoritos se almacenan únicamente en tu dispositivo. Estos datos nunca se transmiten externamente y pueden eliminarse en cualquier momento al desinstalar la Aplicación.

## Servicios de Terceros

La Aplicación se conecta a los siguientes servicios únicamente para obtener contenido para mostrar, como información sobre razas, imágenes y datos de juegos:

| Servicio | Propósito | Datos Enviados | Información de Privacidad |
|----------|-----------|----------------|--------------------------|
| The Cat API | Información de razas (temperamento, estadísticas, historia) y fotos de quiz | Ninguno | [thecatapi.com](https://thecatapi.com) |
| catfact.ninja | Datos curiosos de gatos para la función de trivia | Ninguno | [catfact.ninja](https://catfact.ninja) |

Estas son solicitudes estándar de obtención de contenido. No se incluyen datos personales, identificadores de dispositivo ni información de rastreo.

## Compartición de Datos

No vendemos, alquilamos ni compartimos ningún dato de usuario con terceros. No hay datos que compartir.

## Permisos

| Permiso | Por Qué lo Solicitamos | ¿Requerido? |
|---------|----------------------|-------------|
| Cámara | Para fotografiar gatos para la identificación de raza | Opcional (puedes usar tu biblioteca de fotos) |
| Biblioteca de Fotos | Para seleccionar fotos existentes para la identificación de raza | Opcional (puedes usar la cámara) |

No se solicitan ni acceden otros permisos. La Aplicación no utiliza ubicación, contactos, micrófono, rastreo, notificaciones ni ningún otro acceso sensible.

## Retención y Eliminación de Datos

Ya que no recopilamos datos en nuestros servidores, no hay nada que retener o eliminar de nuestro lado. Todos los datos almacenados localmente, incluidos los favoritos y el historial de escaneos, se eliminan automáticamente cuando desinstalas la Aplicación de tu dispositivo.

## Tus Derechos

Ya que Nekopedia no recopila datos personales, no hay datos de usuario que acceder, exportar, corregir o eliminar de nuestros sistemas. Mantienes el control total sobre todos los datos almacenados localmente en tu dispositivo.

## Privacidad de los Niños

La Aplicación no recopila ninguna información de nadie, incluidos los niños menores de 13 años (o la edad aplicable en tu jurisdicción). Dado que no se recopilan datos personales, la Aplicación es segura para usuarios de todas las edades y cumple con los requisitos de COPPA.

## Usuarios Internacionales

Dado que Nekopedia no recopila datos personales, no se produce ninguna transferencia transfronteriza de información personal. Las solicitudes de contenido a servicios de terceros (información de razas, imágenes, contenido de juegos) no contienen datos personales ni identificadores de dispositivo, independientemente de tu ubicación.

## Cambios en Esta Política

Si actualizamos esta política, la versión revisada se publicará en esta página con una fecha de vigencia actualizada. El uso continuado de la aplicación después de una actualización constituye la aceptación de la política revisada.
