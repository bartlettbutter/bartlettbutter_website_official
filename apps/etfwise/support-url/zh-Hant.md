# 我們能幫您什麼？

我們隨時幫助您充分利用ETFWise。請瀏覽下面的答案，或者如果找不到所需內容，請直接聯絡我們。

## 入門

### 每日推薦如何運作？

每天，ETFWise根據實時市場資料在七大類別（主要指數、行業、債券與固定收益、國際、大宗商品、主題和股息）中挑選頂級ETF。列表全天固定，讓您的檢視保持穩定，同時價格和情緒每5分鐘自動重新整理。點選任何板塊上的"檢視更多"以探索子類別。

### 我需要網際網路連線嗎？

是的，用於實時價格、新聞、情緒和基金資料。看漲和風險理由分析會根據螢幕上已顯示的資料在您的裝置上即時生成，因此無需額外連線。

### ETFWise多少錢？

ETFWise可從App Store免費下載。沒有訂閱，也沒有廣告。

## 常見問題

### 七大ETF類別是什麼？

| 類別 | 涵蓋內容 |
|---|---|
| 主要指數 | 標普500、納斯達克100、羅素2000、道瓊斯、全市場 |
| 行業 | 科技、醫療保健、能源、金融等 |
| 債券與固定收益 | 政府債券、公司債券、高收益、TIPS、市政債券 |
| 國際 | 發達市場、新興市場、單一國家ETF |
| 大宗商品 | 黃金、白銀、石油、農業、廣泛商品籃子 |
| 主題 | AI與機器人、清潔能源、網路安全、雲、電動汽車 |
| 股息 | 高收益、股息增長、貴族股、收益策略 |

### 看漲和風險理由是如何生成的？

ETFWise根據該ETF已顯示的真實資料（價格、回報、情緒、費用率等）在您的裝置上構建每條看漲理由和風險理由。生成即時完成，無需下載或賬戶，也不會向外部伺服器傳送任何內容。

### 新聞情緒如何運作？

應用分析每個ETF最近的新聞文章（7天視窗），並對其積極或消極的語氣進行評分。結果顯示為看跌、消極、中性、積極或看漲。評分旁邊最多顯示3條最新頭條。

### 我可以搜尋特定的ETF嗎？

可以。使用搜尋欄按程式碼或名稱查詢任何ETF。搜尋涵蓋200多個精選ETF，加上總共超過450個程式碼的擴充套件庫。

### 我的資料私密嗎？

是的。沒有賬戶，沒有分析，沒有追蹤。僅將程式碼傳送給金融資料提供商。詳情請參閱我們完整的[隱私政策](https://www.bartlettbutter.com/etfwise/privacy/)。

### 如果我刪除應用會怎樣？

解除安裝ETFWise會永久移除所有本地儲存的資料，包括快取的推薦和生成的分析。由於沒有云備份，此操作無法撤銷。

## 疑難解答

### 價格無法載入

請檢查您的裝置已連線到網際網路。價格每5分鐘自動重新整理一次；如果重新整理失敗，將在下一個週期或您重新開啟應用時更新。

### "無法載入ETF資料"錯誤

這通常意味著網路請求失敗。檢查您的網際網路連線並點選"重試"。

### 看漲和風險理由未顯示

看漲和風險理由是根據ETF的價格、業績和情緒資料構建的。如果它們未出現，說明這些基礎資料尚未載入完成。請確保您已連線到網際網路，然後重新開啟ETF詳情檢視。

### 基金資料（持倉、業績）無法載入

持倉和業績資料需要網際網路連線。如果資料載入失敗，請嘗試關閉並重新開啟ETF詳情檢視。

### 應用崩潰或卡死

請確保您執行的是App Store的最新版本，然後強制關閉應用並重新開啟。如果問題持續，請重啟裝置。如果仍然存在，請透過下方聯絡我們。
