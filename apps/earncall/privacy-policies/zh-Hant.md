**生效日期：** 2026 年 10 月 18 日

EarnCall 由 Bartlett Butter LLC（「我們」）發布。EarnCall 幫助你追蹤公司財報、財務快照、季度趨勢、財報電話會議亮點以及即將到來的財報行事曆。我們以隱私優先建構它：我們不蒐集你的資料，因為我們不需要。

## 簡要版

| 問題 | 答案 |
|------|------|
| 你們蒐集個人資料嗎？ | 否 |
| 有帳戶或登入嗎？ | 否 |
| 有追蹤或分析嗎？ | 否 |
| 有廣告嗎？ | 否 |
| 我的資料會被出售或分享嗎？ | 否 |
| 應用程式對兒童安全嗎？ | 是 |

EarnCall 沒有帳戶，也沒有註冊。它不蒐集、出售或分享任何個人資料，也不含分析或廣告。唯一的網路流量是對公開市場資料的傳出請求。

## 我們蒐集什麼

沒有任何個人內容。EarnCall 沒有帳戶系統、沒有註冊，也沒有分析或廣告 SDK。我們不會為你建立輪廓，也沒有接收你資訊的伺服器。

## 資料如何流動

EarnCall 取得**公開市場資料**，以使應用程式中的數字是真實的。這些是對公開財務資訊的傳出請求，而非上傳任何關於你的內容：

- **Yahoo Finance**：公司財務、每日價格、財報日期以及每股盈餘實際值對一致預期。
- **SEC EDGAR**：來自公開文件的較早財報發布日期。
- **Finnhub**：分析師情緒和財報行事曆。
- **應用程式自有的逐字稿代理**（一個將資料提供方金鑰保存在伺服器端的 Cloudflare Worker）：來自 Alpha Vantage 的財報電話會議逐字稿。

這些請求傳送股票代碼和日期，而非個人資訊。不包含帳戶、使用者識別碼或任何關於你的內容，且這些服務都不會收到任何可識別你身分的內容。

## 裝置端摘要

財報電話會議的要點，即亮點、財測、成長動力和風險，在裝置支援時使用 Apple 的 Foundation Models（Apple Intelligence）**在你的裝置上**生成。在不支援的裝置上，則改為在裝置上選取最相關的逐字稿語句。此摘要的任何內容都不會離開你的裝置。

## 本機儲存的內容

為在下次啟動時立即向你顯示內容，EarnCall 會將最後一次成功取得的公司資料和財報行程以檔案形式快取在你的裝置上。該快取僅存在於你的裝置，絕不會傳送到任何地方，並在你解除安裝應用程式時被移除。

## 權限

EarnCall **完全不請求任何系統權限**——沒有相機、位置、通訊錄、麥克風或照片。應用程式透過網路對公開市場資料發出一般的傳出請求，iOS 不會為一般傳出連線提示授權。

| 權限 | 是否請求？ |
|------|-----------|
| 相機 | 否 |
| 位置 | 否 |
| 通訊錄 | 否 |
| 麥克風 | 否 |
| 照片圖庫 | 否 |
| 應用程式追蹤透明度（ATT） | 否 |

## 我們不做什麼

- 沒有帳戶或註冊。
- 沒有分析、廣告或追蹤 SDK。
- 不跨應用程式或網站追蹤。
- 不向第三方出售或分享資料。

## 非投資建議

EarnCall 僅供參考，並非投資建議。資料可能延遲或不完整；在做出投資決定前請始終自行研究。

## 你的權利

由於我們不在任何伺服器上保存個人資料，因此沒有可供我們提供、更正、轉移或刪除的內容。對於本機快取在你裝置上的一切，你擁有完全的所有權和控制權。

## 兒童隱私

EarnCall 並非面向 13 歲以下兒童，也不會有意從任何人（包括兒童）處蒐集資訊。應用程式對兒童安全，並遵守你所在司法管轄區適用的兒童隱私法規。

## 國際使用者

EarnCall 不蒐集任何個人資料，也不向任何地方傳送任何個人資訊。其唯一的網路流量是對公開市場資料的傳出請求，因此不會發生對你個人資料的跨境傳輸。無論你身處何地，應用程式的運作方式都相同。

## 本政策的變更

如果我們更新本政策，修訂後的版本將連同新的生效日期在此發布。
