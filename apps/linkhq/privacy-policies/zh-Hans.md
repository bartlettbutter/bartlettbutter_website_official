**生效日期：** 2026年3月3日

LinkHQ（“本应用”）是一款面向 iPhone 和 iPad 的免费、仅存本地的链接归档应用。隐私是我们构建它的核心。本政策明确说明使用 LinkHQ 时涉及哪些数据，更重要的是，不涉及哪些数据。

## 简要版

| 问题 | 回答 |
|----------|--------|
| 你们会收集个人数据吗？ | 否 |
| 我的收藏库会被发送到你们的服务器吗？ | 否 |
| 有账户或登录吗？ | 否 |
| 有追踪或分析吗？ | 否 |
| 有广告吗？ | 否 |
| 我的数据会被出售或共享吗？ | 否 |
| 应用对儿童安全吗？ | 是 |

你保存的链接，以及它们的标题、备注、标签和关键词，都留在你的设备上。我们不运营任何接收你数据的服务器。LinkHQ 唯一使用网络的时刻，是查询链接自身的元数据，如下所述。

## 收集了哪些数据

**没有。** LinkHQ 没有用户账户，没有分析平台，没有广告 SDK，也没有任何形式的追踪机制。我们不收集、不存储、也不传输个人信息。

## 应用如何在本地使用数据

### 你保存的链接

你保存的链接，连同它们的标题、备注、标签、关键词、来源、收藏状态和打开状态，都只存储在你的设备上，位于一个共享的应用容器中，以便主应用和它的共享扩展读取同一份数据来源。它们绝不会被上传。

### 从共享菜单捕获

当你把链接分享进 LinkHQ 时，共享扩展会读取分享的网址，或分享文本中夹带的链接，以便保存。这发生在你的设备上。关于此次分享的任何内容都不会被发送到我们控制的任何服务器。

### 设备端关键词提取

保存链接时，会在你的设备上提取若干描述其内容的关键词，用于搜索和筛选。这一过程使用 Apple 的设备端自然语言框架在本地运行。为此不会向任何地方发送任何文本。

## 唯一的网络用途：逐条链接的元数据查询

为了显示链接真正的标题和预览图，而不是一串裸网址，LinkHQ 会在保存链接时执行一次逐条链接的元数据查询，有时还会在应用中再查询一次，以补齐那些在查询完成前就被保存的链接。

- 请求会发往**每个链接自己的站点**，或**该平台的 oEmbed 端点**（例如 YouTube、TikTok 或 X），与你的浏览器为该链接访问的目的地相同。
- 只读取标题、描述、站点关键词和预览图网址。只存储图片网址，绝不存储图片本身；预览图在显示时才从站点加载。
- 这些请求不会发送到任何由我们运营的服务器，并且不携带任何账户或标识符，因为根本没有。
- **你的收藏库绝不会被上传。** 查询针对的是单个链接的公开页面，而非你的整个收藏。

无法连上站点的查询，例如在你离线时，只会把标题或缩略图留待下次启动时补齐。

## 权限

LinkHQ 不请求任何敏感的设备权限。

| 权限 | 状态 |
|------------|--------|
| **麦克风** | 不请求 |
| **相机** | 不请求 |
| **通讯录** | 不请求 |
| **照片** | 不请求 |
| **健康数据** | 不请求 |
| **位置** | 不请求 |

从共享菜单保存链接并在来源处重新打开它们，都不需要上述任何权限。

## 第三方服务

LinkHQ 不集成任何第三方分析、广告或追踪服务。元数据查询直接联系每个链接自己的站点或该平台的公开 oEmbed 端点，关键词提取使用 Apple 的设备端框架，作为操作系统的一部分在你的设备上运行。

## 数据共享

我们不会向任何人出售、出租、授权或共享你的数据。LinkHQ 不会产生任何传输你的收藏库、备注、标签或关键词的网络流量。

## 数据保留与删除

我们的服务器上不存储任何数据，因此我方无任何内容需要保留或删除。你设备上的一切，你保存的链接及其所有详情，都会在你删除应用的那一刻移除。设置中还包含“全部删除”操作，可就地清空你的收藏库。

## 你的权利

由于我们什么都不收集，我方不存在可供访问、更正、可携或抹除的个人数据。通过管理或移除应用，你对所有本地存储的内容拥有完全控制。

## 儿童隐私

LinkHQ 不会从任何人收集信息，包括 13 岁以下（或你所在司法辖区的适用年龄）的儿童。由于不收集任何个人数据，本应用对所有年龄段的用户都是安全的。

## 国际用户

由于 LinkHQ 不收集任何个人数据，不发生个人信息的跨境传输。逐条链接的元数据查询会访问托管你所保存链接的那个站点。

## 本政策的变更

如果我们更新本政策，修订版本会连同新的生效日期发布于此。更新后继续使用本应用即表示接受修订后的政策。
