**시행일:** 2026년 6월 13일

Nekopedia("본 앱")는 사진으로 고양이 품종을 식별하는 무료 iOS 애플리케이션입니다. 개인정보 보호는 나중에 덧붙인 것이 아니라, 본 앱이 첫날부터 만들어진 방식 그 자체입니다. 본 방침은 귀하의 정보가 실제로 어떻게 처리되는지 쉬운 언어로 설명합니다. 간단히 말해, 정보는 귀하에게 그대로 남습니다.

## 요약 버전

| 질문 | 답변 |
|------|------|
| 개인 데이터를 수집하나요? | 아니요 |
| 내 사진이 기기 밖으로 나가나요? | 아니요 |
| 계정이나 로그인이 있나요? | 아니요 |
| 추적이나 분석이 있나요? | 아니요 |
| 광고가 있나요? | 아니요 |
| 내 데이터가 판매되거나 공유되나요? | 아니요 |
| 어린이가 앱을 안전하게 사용할 수 있나요? | 예 |

귀하의 사진은 전적으로 기기에서 처리되며 기기를 떠나지 않습니다. 품종 식별은 완전히 오프라인으로 작동합니다. 본 앱이 하는 유일한 네트워크 요청은 품종 정보, 이미지, 게임 콘텐츠를 표시하기 위해 가져오는 것입니다.

## 수집하는 데이터

없음. 개인 데이터를 수집, 저장 또는 전송하지 않습니다. 본 앱에는 사용자 계정, 분석 SDK, 광고 프레임워크, 제3자 추적 도구가 포함되어 있지 않습니다.

## 사진 및 카메라/라이브러리 접근

본 앱은 품종 식별을 위해 고양이 사진을 촬영하거나 선택할 수 있도록 카메라 및 사진 라이브러리 권한만을 요청합니다. 촬영하거나 선택한 사진은 기기 내 인텔리전스를 사용하여 완전히 기기에서 분석됩니다. 귀하의 사진은 어떤 서버에도 업로드되지 않습니다.

## 로컬에 저장되는 데이터

즐겨찾기에 저장한 품종 스캔 결과는 기기에만 저장됩니다. 이 데이터는 외부로 전송되지 않으며 앱을 삭제하여 언제든지 제거할 수 있습니다.

## 제3자 서비스

본 앱은 품종 정보, 이미지, 게임 데이터 등의 표시 콘텐츠를 가져오기 위해서만 다음 서비스에 연결합니다:

| 서비스 | 목적 | 전송 데이터 | 개인정보 정보 |
|--------|------|-----------|-------------|
| The Cat API | 품종 정보(성격, 통계, 역사) 및 퀴즈 사진 | 없음 | [thecatapi.com](https://thecatapi.com) |
| catfact.ninja | 트리비아 기능을 위한 고양이 상식 | 없음 | [catfact.ninja](https://catfact.ninja) |

이것들은 표준 콘텐츠 가져오기 요청입니다. 개인 데이터, 기기 식별자 또는 추적 정보가 포함되지 않습니다.

## 데이터 공유

사용자 데이터를 제3자에게 판매, 임대 또는 공유하지 않습니다. 공유할 데이터가 없습니다.

## 권한

| 권한 | 요청 이유 | 필수? |
|------|----------|-------|
| 카메라 | 품종 식별을 위해 고양이를 촬영 | 선택 사항(사진 라이브러리를 대신 사용할 수 있음) |
| 사진 라이브러리 | 품종 식별을 위해 기존 사진 선택 | 선택 사항(카메라를 대신 사용할 수 있음) |

다른 권한은 요청되거나 접근되지 않습니다. 본 앱은 위치, 연락처, 마이크, 추적, 알림 또는 기타 민감한 접근을 사용하지 않습니다.

## 데이터 보존 및 삭제

서버에서 데이터를 수집하지 않으므로 당사 측에서 보존하거나 삭제할 것이 없습니다. 즐겨찾기 및 스캔 기록을 포함한 모든 로컬 저장 데이터는 기기에서 앱을 삭제하면 자동으로 제거됩니다.

## 귀하의 권리

Nekopedia는 개인 데이터를 수집하지 않으므로, 당사 시스템에서 접근, 내보내기, 수정 또는 삭제할 사용자 데이터가 없습니다. 귀하는 기기에 로컬로 저장된 모든 데이터에 대한 완전한 통제권을 유지합니다.

## 어린이 개인정보 보호

본 앱은 13세 미만 어린이(또는 귀하의 관할권에서 적용되는 연령)를 포함하여 누구로부터도 정보를 수집하지 않습니다. 개인 데이터가 수집되지 않으므로 본 앱은 모든 연령의 사용자에게 안전하며 COPPA 요구사항을 준수합니다.

## 국제 사용자

Nekopedia는 개인 데이터를 수집하지 않으므로 개인 정보의 국경 간 이전이 발생하지 않습니다. 제3자 서비스(품종 정보, 이미지, 게임 콘텐츠)에 대한 콘텐츠 가져오기 요청에는 귀하의 위치에 관계없이 개인 데이터나 기기 식별자가 포함되지 않습니다.
