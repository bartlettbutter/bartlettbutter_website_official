**시행일:** 2026년 9월 17일

TrafficVibe("본 앱")는 실시간 교통, 날씨, 지도 데이터로 구성한 쉬운 말의 아침 출근길 브리핑을 제공하는 무료 iOS 애플리케이션입니다. 개인정보 보호는 우리가 이 앱을 만든 방식의 근간입니다. 여러분의 정보가 어떻게 처리되는지 정확히 설명드립니다.

## 요약

| 질문 | 답변 |
|----------|--------|
| 개인 데이터를 수집하나요? | 아니요 |
| 계정이나 로그인이 있나요? | 아니요 |
| 추적이나 분석이 있나요? | 아니요 |
| 광고가 있나요? | 아니요 |
| 내 데이터가 판매되거나 공유되나요? | 아니요 |
| 앱이 내 위치를 사용하나요? | 사용자가 켠 경우에만, 그리고 오직 기기에서만 |
| 어린이가 앱을 안전하게 사용할 수 있나요? | 예 |

외부로 전송되는 유일한 데이터는 상황을 가져오는 데 필요한 것 — 예컨대 지명이나 좌표 — 으로, 여러분의 브리핑을 구동하는 지도·날씨·공공 데이터 제공업체로 보내집니다.

## 우리가 수집하는 데이터

우리 서버에는 아무것도 없습니다. TrafficVibe에는 사용자 계정도, 사용 분석도, 광고나 추적 프레임워크도 없습니다. 우리는 여러분의 정보를 받거나 저장하는 백엔드를 운영하지 않습니다.

## 위치

TrafficVibe는 여러분의 위치를 사용해 "현재 위치" 도시를 설정함으로써 브리핑이 실제로 있는 곳을 반영하도록 할 수 있습니다. 이는 선택 사항이며 여러분의 허가("사용 중에만" 위치 권한)가 있을 때만 요청됩니다. 여러분의 위치는 기기에서 상황을 조회하는 데 사용되며, 결과를 반환하는 데 필요한 좌표로만 해당 제공업체에 대한 요청에 포함됩니다. 우리 서버에는 결코 저장되지 않습니다. 우리에게는 서버가 없기 때문입니다.

## 기기에 남는 것

모든 앱 데이터는 여러분의 기기에 로컬로 저장됩니다:

- 저장한 출근 도시와 경로
- 단위, 시간 형식, 알림 설정 등의 기본 설정
- 앱이 빠르게 열리도록 최근 상황을 저장한 사본

이 데이터는 오직 여러분의 기기에만 존재하며 외부 서버로 결코 업로드되지 않습니다.

## 제3자 서비스

브리핑을 구성하기 위해 TrafficVibe는 검증된 지도·날씨·공공 데이터 제공업체에 데이터를 요청합니다. 각 요청은 여러분이 보고 있는 장소에 대한 결과를 반환하는 데 필요한 것 — 위치 또는 지역 — 만 담으며, 여러분의 신원은 결코 담지 않습니다.

| 우리가 요청하는 것 | 이유 | 전송되는 것 |
|---|---|---|
| 경로 안내, 예상 도착 시간, 근처 장소 | 출근길을 추정하고 지도 특성을 표시하기 위해 | 관련 좌표 |
| 날씨 상황 | 경로 위의 비, 눈, 결빙, 안개, 눈부심을 표시하기 위해 | 관련 좌표 |
| 지역 지도 특성과 공휴일 | 통행료, 건널목, 카메라, 더 한산한 날을 드러내기 위해 | 지역 또는 국가/날짜 |
| 유가 | 주유하기에 저렴한 주인지 비싼 주인지 보여주기 위해 | 지역 또는 국가 |

이 요청에는 계정, 기기 식별자, 연락처, 추적 정보가 결코 포함되지 않으며, 어떤 제공업체도 여러분에 대한 프로필을 받지 않습니다.

## 기기 내 처리

여러분의 브리핑과 그 모든 평가는 TrafficVibe가 가져온 상황으로부터 여러분의 기기에서 구성됩니다. 여러분의 출근길 — 여러분이 관심 있는 도시와 경로 — 은 그 상황을 요청하기 위해 기기에서 사용되며, 결코 업로드되거나 프로파일링되거나 공유되지 않습니다.

## 알림

출발 리마인더, 지연 경고, 사고 알림은 여러분의 기기에서 예약되고 평가됩니다. 알림을 켜더라도 우리나 어떤 제3자에게도 개인 데이터가 전송되지 않습니다.

## 데이터 공유

우리는 여러분의 데이터를 어떤 제3자에게도 판매하거나, 대여하거나, 공유하지 않습니다. 우리에게는 데이터 공유 계약도, 광고 파트너도, 분석 제공업체도 없습니다.

## 권한

TrafficVibe는 선택 사항인 현재 위치 도시를 제공하기 위해서만 위치 접근을 요청하고, 여러분이 알림을 켜기로 선택한 경우에만 알림 접근을 요청합니다. 카메라, 연락처, 마이크, 건강 데이터, 사진에 대한 접근은 요청하지 않으며, App Tracking Transparency를 사용하지 않습니다.

## 데이터 보관 및 삭제

우리는 서버에 개인 데이터를 전혀 수집하지 않으므로, 우리 쪽에서 보관하거나 삭제할 것이 없습니다. 로컬에 저장된 모든 데이터 — 저장한 도시, 기본 설정, 캐시된 상황 — 는 기기에서 앱을 삭제하면 영구적으로 제거됩니다.

## 여러분의 권리

TrafficVibe는 어떤 서버에도 개인 데이터를 수집하거나 저장하지 않으므로, 우리 시스템에서 접근, 정정, 내보내기, 삭제할 개인 데이터가 없습니다. 여러분은 기기에서 앱을 관리하거나 제거함으로써 로컬에 저장된 모든 데이터를 완전히 통제할 수 있습니다.

## 어린이 개인정보 보호

TrafficVibe는 13세 미만(또는 해당 관할권의 적용 연령)의 어린이를 포함해 그 누구로부터도 고의로 개인 정보를 수집하지 않습니다. 본 앱은 우리 서버에 개인 데이터를 전혀 수집하지 않으므로 COPPA 요건을 준수합니다.

## 국제 사용자

TrafficVibe는 전 세계에서 작동합니다. 우리 서버에 개인 데이터를 전혀 수집하지 않으므로 개인 정보의 국경 간 이전이 발생하지 않습니다. 데이터 제공업체에 대한 요청은, 여러분이 어디에 있든, 상황을 반환하는 데 필요한 위치나 지역만 담습니다.
