**Data de vigência:** 13 de junho de 2026

Nekopedia ("o Aplicativo") é um aplicativo iOS gratuito que identifica raças de gatos a partir de fotos. Sua privacidade é fundamental na forma como construímos este aplicativo. Veja exatamente como suas informações são tratadas.

## Versão Resumida

| Pergunta | Resposta |
|----------|----------|
| Vocês coletam dados pessoais? | Não |
| Minhas fotos saem do meu dispositivo? | Não |
| Existem contas ou logins? | Não |
| Existe rastreamento ou análises? | Não |
| Existem anúncios? | Não |
| Meus dados são vendidos ou compartilhados? | Não |
| Crianças podem usar o aplicativo com segurança? | Sim |

Suas fotos são processadas inteiramente no seu dispositivo e nunca saem dele. A identificação de raças funciona completamente offline. As únicas solicitações de rede que o Aplicativo faz são para buscar informações sobre raças, imagens e conteúdo de jogos para exibição.

## Dados que Coletamos

Nenhum. Não coletamos, armazenamos ou transmitimos nenhum dado pessoal. O Aplicativo não contém contas de usuário, SDKs de análise, frameworks de publicidade ou ferramentas de rastreamento de terceiros.

## Fotos e Acesso à Câmera/Biblioteca

O Aplicativo solicita permissões de câmera e biblioteca de fotos unicamente para permitir que você fotografe ou selecione imagens de gatos para identificação de raça. As fotos que você tira ou seleciona são analisadas inteiramente no seu dispositivo usando inteligência local. Suas fotos nunca são enviadas a nenhum servidor.

## Dados Armazenados Localmente

Os resultados de escaneamento de raças que você salva nos Favoritos são armazenados apenas no seu dispositivo. Esses dados nunca são transmitidos externamente e podem ser removidos a qualquer momento ao excluir o Aplicativo.

## Serviços de Terceiros

O Aplicativo se conecta aos seguintes serviços unicamente para buscar conteúdo de exibição, como informações sobre raças, imagens e dados de jogos:

| Serviço | Propósito | Dados Enviados | Informações de Privacidade |
|---------|-----------|----------------|---------------------------|
| The Cat API | Informações de raças (temperamento, estatísticas, história) e fotos de quiz | Nenhum | [thecatapi.com](https://thecatapi.com) |
| catfact.ninja | Fatos sobre gatos para o recurso de trivia | Nenhum | [catfact.ninja](https://catfact.ninja) |

Estas são solicitações padrão de busca de conteúdo. Nenhum dado pessoal, identificador de dispositivo ou informação de rastreamento é incluído.

## Compartilhamento de Dados

Não vendemos, alugamos ou compartilhamos nenhum dado de usuário com terceiros. Não há dados para compartilhar.

## Permissões

| Permissão | Por Que Solicitamos | Obrigatória? |
|-----------|-------------------|--------------|
| Câmera | Para fotografar gatos para identificação de raça | Opcional (você pode usar sua biblioteca de fotos) |
| Biblioteca de Fotos | Para selecionar fotos existentes para identificação de raça | Opcional (você pode usar a câmera) |

Nenhuma outra permissão é solicitada ou acessada. O Aplicativo não usa localização, contatos, microfone, rastreamento, notificações ou qualquer outro acesso sensível.

## Retenção e Exclusão de Dados

Como não coletamos dados em nossos servidores, não há nada para reter ou excluir do nosso lado. Todos os dados armazenados localmente, incluindo favoritos e histórico de escaneamentos, são automaticamente removidos quando você exclui o Aplicativo do seu dispositivo.

## Seus Direitos

Como o Nekopedia não coleta dados pessoais, não há dados de usuário para acessar, exportar, corrigir ou excluir de nossos sistemas. Você mantém controle total sobre todos os dados armazenados localmente no seu dispositivo.

## Privacidade das Crianças

O Aplicativo não coleta nenhuma informação de ninguém, incluindo crianças menores de 13 anos (ou a idade aplicável na sua jurisdição). Como nenhum dado pessoal é coletado, o Aplicativo é seguro para usuários de todas as idades e está em conformidade com os requisitos COPPA.

## Usuários Internacionais

Como o Nekopedia não coleta dados pessoais, nenhuma transferência transfronteiriça de informações pessoais ocorre. As solicitações de busca de conteúdo para serviços de terceiros (informações de raças, imagens, conteúdo de jogos) não contêm dados pessoais ou identificadores de dispositivo, independentemente da sua localização.

## Alterações nesta Política

Se atualizarmos esta política, a versão revisada será publicada nesta página com uma data de vigência atualizada. O uso continuado do aplicativo após uma atualização constitui aceitação da política revisada.

## Fale Conosco

Se você tiver dúvidas sobre esta política de privacidade, envie um e-mail para [contact@bartlettbutter.com](mailto:contact@bartlettbutter.com).
