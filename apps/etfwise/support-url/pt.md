# Como podemos ajudar?

Estamos aqui para ajudar você a aproveitar ao máximo o ETFWise. Navegue pelas respostas abaixo ou entre em contato diretamente se não encontrar o que precisa.

## Primeiros Passos

### Como funcionam as recomendações diárias?

Todos os dias, o ETFWise seleciona os principais ETFs em sete categorias (Índice Principal, Setor, Títulos e Renda Fixa, Internacional, Commodities, Temática e Dividendos) com base em dados de mercado ao vivo. A lista é fixada durante todo o dia para que sua visualização permaneça estável, enquanto os preços e o sentimento são atualizados automaticamente a cada 5 minutos. Toque em "Ver mais" em qualquer seção para explorar subcategorias.

### Preciso de uma chave de API?

Uma chave de API gratuita da Finnhub desbloqueia preços ao vivo, notícias e dados de analistas. Você pode obter uma em [finnhub.io](https://finnhub.io) e inseri-la na primeira inicialização. Se você pular essa etapa, o aplicativo funciona com dados de demonstração integrados para que você possa explorar toda a interface.

### Preciso de conexão com a internet?

Sim, para preços ao vivo, notícias, sentimento e dados de fundos. A análise dos argumentos de alta e de risco é gerada instantaneamente no seu dispositivo a partir dos dados já exibidos na tela, portanto não precisa de nenhuma conexão adicional.

### Quanto custa o ETFWise?

O ETFWise é gratuito para baixar na App Store. Não há assinaturas nem anúncios.

## Perguntas Frequentes

### Quais são as sete categorias de ETF?

| Categoria | O Que Abrange |
|---|---|
| Índice Principal | S&P 500, Nasdaq 100, Russell 2000, Dow Jones, Mercado Total |
| Setor | Tecnologia, Saúde, Energia, Financeiro e mais |
| Títulos e Renda Fixa | Títulos do governo, corporativos, alto rendimento, TIPS, municipais |
| Internacional | Mercados desenvolvidos, mercados emergentes, ETFs de país único |
| Commodities | Ouro, prata, petróleo, agricultura, cestas amplas de commodities |
| Temática | IA e robótica, energia limpa, cibersegurança, nuvem, veículos elétricos |
| Dividendos | Alto rendimento, crescimento de dividendos, aristocratas, estratégias de renda |

### Como os argumentos de alta e de risco são gerados?

O ETFWise cria cada argumento de alta e de risco no seu dispositivo a partir dos dados reais já exibidos para aquele ETF: preço, retornos, sentimento, taxa de despesas e mais. A geração é instantânea, não requer download nem conta, e nada é enviado a servidores externos.

### Como funciona o sentimento de notícias?

O aplicativo analisa artigos de notícias recentes (janela de 7 dias) para cada ETF e os pontua quanto ao tom positivo ou negativo. O resultado é exibido como Baixista, Negativo, Neutro, Positivo ou Altista. Até 3 manchetes recentes são exibidas ao lado da pontuação.

### Posso pesquisar um ETF específico?

Sim. Use a barra de busca para encontrar qualquer ETF por símbolo ou nome. A busca abrange mais de 200 ETFs selecionados, além de uma biblioteca estendida de mais de 400 tickers no total.

### Meus dados são privados?

Sim. Sem contas, sem análises, sem rastreamento. Apenas símbolos de tickers são enviados aos provedores de dados financeiros. Consulte nossa [Política de Privacidade](https://www.bartlettbutter.com/etfwise/privacy/) completa para mais detalhes.

### O que acontece se eu excluir o aplicativo?

Desinstalar o ETFWise remove permanentemente todos os dados armazenados localmente, incluindo recomendações em cache, análise gerada e sua chave de API. Como não há backup na nuvem, isso não pode ser desfeito.

## Solução de Problemas

### Os preços não carregam

Certifique-se de ter inserido uma chave de API válida da Finnhub (obtenha uma gratuitamente em [finnhub.io](https://finnhub.io)) e verifique se o seu dispositivo está conectado à internet. Se você pulou a etapa da chave de API, o aplicativo exibe dados de demonstração em vez de preços ao vivo, o que é o comportamento esperado.

### Erro "Não foi possível carregar os dados do ETF"

Isso geralmente significa que uma solicitação de rede falhou. Verifique sua conexão com a internet e toque em "Tentar novamente". Se você estiver usando uma chave de API da Finnhub, verifique se ela está inserida corretamente nas configurações do aplicativo.

### Os argumentos de alta e de risco não estão aparecendo

Os argumentos de alta e de risco são criados a partir dos dados de preço, desempenho e sentimento de um ETF. Se não aparecerem, esses dados subjacentes ainda não terminaram de carregar: certifique-se de estar conectado à internet e, em seguida, reabra a visualização de detalhes do ETF.

### Os dados do fundo (participações, desempenho) não carregam

Os dados de participações e desempenho exigem conexão com a internet. Se os dados não carregarem, tente fechar e reabrir a visualização de detalhes do ETF.

### O aplicativo está travando ou congelando

Certifique-se de estar usando a versão mais recente da App Store, depois force o encerramento do aplicativo e reabra-o. Se o problema continuar, reinicie o dispositivo. Se ainda persistir, entre em contato conosco abaixo.

## Compatibilidade

O ETFWise requer iOS 18.0 ou posterior e funciona tanto no iPhone quanto no iPad.
