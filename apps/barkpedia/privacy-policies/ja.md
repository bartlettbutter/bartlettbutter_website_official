**発効日：** 2026年4月11日

Barkpedia（「本アプリ」）は、写真から犬種を識別する無料のiOSアプリケーションです。あなたのプライバシーは、私たちがこのアプリを開発する上での基本です。ここでは、お客様の情報がどのように扱われるかを正確に説明します。

## 簡単な概要

| 質問 | 回答 |
|------|------|
| 個人データを収集しますか？ | いいえ |
| 私の写真はデバイスから出ますか？ | いいえ |
| アカウントやログインはありますか？ | いいえ |
| トラッキングや分析はありますか？ | いいえ |
| 広告はありますか？ | いいえ |
| 私のデータは販売または共有されますか？ | いいえ |
| 子どもが安全にアプリを使用できますか？ | はい |

## 収集するデータ

**ありません。** 私たちはいかなる個人データも収集、保存、送信しません。本アプリには、ユーザーアカウント、分析SDK、広告フレームワーク、サードパーティのトラッキングツールは含まれていません。

## 写真の取り扱い

本アプリは、犬種識別のために犬の画像を撮影または選択できるようにする目的のみで、カメラおよび写真ライブラリの権限を要求します。撮影または選択した写真は、デバイス上のインテリジェンスを使用して完全にデバイス上で分析されます。**あなたの写真がサーバーにアップロードされることは一切ありません。**

## デバイスに保存される内容

- **お気に入り** — 保存を選択した犬種スキャン結果は、あなたのデバイス上にのみローカルに保存されます。
- **探索データ** — 犬種検索インデックスと原産国マップデータは、アプリ自体に組み込まれています。
- **マップの描画** — インタラクティブな世界地図はApple マップ（MapKit）を使用しており、あなたのデバイス上でローカルに描画されます。

これらのデータはいずれも外部に送信されません。すべて、アプリを削除すると自動的に削除されます。

## ネットワークリクエスト

本アプリは、表示コンテンツ（犬種プロフィール、画像、ゲームの問題）を取得する目的のみで、以下のサービスに接続します。

| サービス | 目的 | 送信される個人データ |
|----------|------|---------------------|
| The Dog API | 犬種情報（気質、統計、歴史） | なし |
| dogapi.dog | 追加の犬種情報とトリビア用の犬に関する豆知識 | なし |
| Dog CEO API | 犬種の画像とクイズの写真 | なし |
| Wikipedia | 犬種の参照画像 | なし |

これらは標準的なコンテンツ取得リクエストです。いかなるリクエストにも、個人データ、デバイス識別子、トラッキング情報は含まれていません。

## データの共有

私たちは、いかなるユーザーデータも第三者に販売、貸与、共有しません。共有すべきユーザーデータはありません。

## 要求する権限

| 権限 | 要求する理由 | 必須ですか？ |
|------|------------|-------------|
| カメラ | 犬種識別のために犬を撮影するため | 任意 — 写真ライブラリを使用できます |
| 写真ライブラリ | 犬種識別のために既存の写真を選択するため | 任意 — カメラを使用できます |

**以上です。** 本アプリは、位置情報、連絡先、マイク、Bluetooth、トラッキング（ATT）、通知、その他の機密性の高い権限を要求したりアクセスしたりすることはありません。

## データの保持と削除

私たちはサーバー上でデータを一切収集しないため、私たちの側で保持または削除するものはありません。お気に入りやスキャン履歴を含むすべてのローカル保存データは、デバイスからアプリを削除すると自動的に削除されます。

## あなたの権利

Barkpediaは個人データを収集しないため、私たちのシステムからアクセス、エクスポート、修正、削除するユーザーデータはありません。あなたはデバイス上にローカルに保存されているすべてのものを完全に管理できます。

## 子どものプライバシー

本アプリは、13歳未満の子ども（またはお住まいの管轄区域で適用される年齢）を含め、誰からも情報を収集しません。個人データが収集されないため、本アプリはあらゆる年齢のユーザーにとって安全であり、COPPAの要件に準拠しています。

## 国際的なユーザー

Barkpediaは個人データを収集しないため、個人情報の国境を越えた転送は発生しません。サードパーティサービスへのコンテンツ取得リクエスト（犬種情報、画像）には、お客様の所在地に関係なく、個人データやデバイス識別子は含まれていません。

## 本ポリシーの変更

本ポリシーを更新する場合、改訂版は更新された発効日とともにこのページに掲載されます。更新後もアプリの使用を継続することは、改訂されたポリシーへの同意を意味します。
