**生效日期：** 2026 年 10 月 18 日

EarnCall 由 Bartlett Butter LLC（“我们”）发布。EarnCall 帮助你追踪公司财报、财务快照、季度趋势、财报电话会议亮点以及即将到来的财报日历。我们以隐私优先构建它：我们不收集你的数据，因为我们不需要。

## 简要版

| 问题 | 答案 |
|------|------|
| 你们收集个人数据吗？ | 否 |
| 有账户或登录吗？ | 否 |
| 有追踪或分析吗？ | 否 |
| 有广告吗？ | 否 |
| 我的数据会被出售或共享吗？ | 否 |
| 应用对儿童安全吗？ | 是 |

EarnCall 没有账户，也没有注册。它不收集、出售或共享任何个人数据，也不含分析或广告。唯一的网络流量是对公开市场数据的出站请求。

## 我们收集什么

没有任何个人内容。EarnCall 没有账户系统、没有注册，也没有分析或广告 SDK。我们不会为你建立画像，也没有接收你信息的服务器。

## 数据如何流动

EarnCall 获取**公开市场数据**，以使应用中的数字是真实的。这些是对公开财务信息的出站请求，而非上传任何关于你的内容：

- **Yahoo Finance**：公司财务、每日价格、财报日期以及每股收益实际值对一致预期。
- **SEC EDGAR**：来自公开文件的较早财报发布日期。
- **Finnhub**：分析师情绪和财报日历。
- **应用自有的文字记录代理**（一个将数据提供方密钥保存在服务器端的 Cloudflare Worker）：来自 Alpha Vantage 的财报电话会议文字记录。

这些请求发送股票代码和日期，而非个人信息。不包含账户、用户标识符或任何关于你的内容，且这些服务都不会收到任何可识别你身份的内容。

## 设备端摘要

财报电话会议的要点，即亮点、指引、增长驱动和风险，在设备支持时使用 Apple 的 Foundation Models（Apple Intelligence）**在你的设备上**生成。在不支持的设备上，则改为在设备上选取最相关的文字记录语句。此摘要的任何内容都不会离开你的设备。

## 本地存储的内容

为在下次启动时立即向你显示内容，EarnCall 会将最后一次成功获取的公司数据和财报日程以文件形式缓存在你的设备上。该缓存仅存在于你的设备，绝不会发送到任何地方，并在你卸载应用时被移除。

## 权限

EarnCall **完全不请求任何系统权限**——没有相机、位置、通讯录、麦克风或照片。应用通过网络对公开市场数据发出普通的出站请求，iOS 不会为普通出站连接提示授权。

| 权限 | 是否请求？ |
|------|-----------|
| 相机 | 否 |
| 位置 | 否 |
| 通讯录 | 否 |
| 麦克风 | 否 |
| 照片图库 | 否 |
| 应用追踪透明度（ATT） | 否 |

## 我们不做什么

- 没有账户或注册。
- 没有分析、广告或追踪 SDK。
- 不跨应用或网站追踪。
- 不向第三方出售或共享数据。

## 非投资建议

EarnCall 仅供参考，并非投资建议。数据可能延迟或不完整；在做出投资决定前请始终自行研究。

## 你的权利

由于我们不在任何服务器上保存个人数据，因此没有可供我们提供、更正、转移或删除的内容。对于本地缓存在你设备上的一切，你拥有完全的所有权和控制权。

## 儿童隐私

EarnCall 并非面向 13 岁以下儿童，也不会有意从任何人（包括儿童）处收集信息。应用对儿童安全，并遵守你所在司法辖区适用的儿童隐私法规。

## 国际用户

EarnCall 不收集任何个人数据，也不向任何地方发送任何个人信息。其唯一的网络流量是对公开市场数据的出站请求，因此不会发生对你个人数据的跨境传输。无论你身处何地，应用的运行方式都相同。

## 本政策的变更

如果我们更新本政策，修订后的版本将连同新的生效日期在此发布。
