**生效日期：** 2026年4月25日

ETFWise（"本应用"）是一款免费的iOS应用程序，通过实时市场数据和设备端即时分析提供每日ETF推荐。您的隐私是我们构建此应用的核心理念。以下是您的信息被处理方式的详细说明。

## 简要版本

| 问题 | 回答 |
|------|------|
| 你们收集个人数据吗？ | 否 |
| 有账户或登录吗？ | 否 |
| 有追踪或分析吗？ | 否 |
| 有广告吗？ | 否 |
| 我的数据会被出售或共享吗？ | 否 |
| 分析会离开我的设备吗？ | 否 |
| 儿童可以安全使用该应用吗？ | 是 |

唯一对外发送的数据是用于获取市场数据的ETF代码。您的Finnhub API密钥安全地存储在设备上，且仅发送给Finnhub。

## 我们收集的数据

无。我们不会向服务器收集、存储或传输任何个人信息。ETFWise没有用户账户、没有使用分析，也没有广告或追踪框架。

## 保留在您设备上的内容

所有应用数据都存储在您的设备本地：

- 每日ETF推荐和缓存的市场价格
- 新闻情绪评分和生成的分析
- 您的Finnhub API密钥（安全地存储在设备端存储中）

这些数据每日刷新，永远不会上传到外部服务器。

## 第三方服务

ETFWise连接第三方金融数据提供商仅用于获取市场数据以供显示。如果您选择提供，您自己的Finnhub API密钥将用于实时报价和新闻。

| 发送的数据 | 包含的个人数据 |
|---|---|
| ETF代码和日期范围 | 无 |
| 您的Finnhub API密钥（仅发送给Finnhub，用于身份验证） | 无 |

任何请求中都不包含设备标识符、位置或追踪信息。

## 设备端分析

看涨理由、风险理由和基金描述完全在您的设备上根据已为每个ETF获取的市场数据生成。此分析不涉及任何单独下载，也不涉及外部服务器。与之相关的任何内容都不会离开您的设备。

## API密钥安全

如果您输入Finnhub API密钥，它将安全地存储在您的设备上，并仅传输至Finnhub的API进行身份验证。它永远不会发送到其他任何地方或与任何其他方共享。

## 数据共享

我们不向任何第三方出售、出租或共享您的数据。我们没有数据共享协议、没有广告合作伙伴，也没有分析提供商。

## 权限

ETFWise不请求访问您的相机、位置、通讯录、麦克风、健康数据、照片或应用追踪透明度。使用本应用无需任何特殊权限。

## 数据保留和删除

由于我们不在服务器上收集任何个人数据，因此我们这边没有需要保留或删除的内容。所有本地存储的数据，包括推荐、缓存价格、生成的分析和您的API密钥，都会在您从设备上删除应用时被永久移除。

## 您的权利

由于ETFWise不在任何服务器上收集或存储个人数据，我们的系统中没有个人数据可供访问、更正、导出或删除。您通过管理或移除设备上的应用来对所有本地存储的数据保持完全控制。

## 儿童隐私

ETFWise不会在知情的情况下收集任何人的个人信息，包括13岁以下的儿童（或您所在司法管辖区适用的年龄）。由于本应用完全不收集个人数据，因此符合COPPA要求。

## 国际用户

由于ETFWise不收集个人数据，因此不会发生个人信息的跨境传输。向金融数据提供商发出的代码请求不包含任何个人数据或设备标识符，无论您身处何地。

## 本政策的变更

如果我们更新此政策，修订版本将在此页面发布，并附有更新的生效日期。更新后继续使用该应用即表示接受修订后的政策。
