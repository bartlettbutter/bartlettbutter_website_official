**発効日：** 2026年3月3日

LinkHQ（「本アプリ」）は、iPhone と iPad 向けの無料で端末内だけのリンクアーカイブです。プライバシーは本アプリを作るうえでの中心にあります。本ポリシーは、LinkHQ を使うときにどのデータが関わるのか、そしてより重要なことに、どのデータが関わらないのかを明確に説明します。

## 短い要約

| 質問 | 回答 |
|----------|--------|
| 個人データを集めますか？ | いいえ |
| 私のライブラリはサーバーに送られますか？ | いいえ |
| アカウントやログインはありますか？ | いいえ |
| 追跡や解析はありますか？ | いいえ |
| 広告はありますか？ | いいえ |
| 私のデータは売られたり共有されたりしますか？ | いいえ |
| アプリは子どもにとって安全ですか？ | はい |

あなたが保存したリンク、そしてその題名、メモ、タグ、キーワードは、すべてあなたの端末にとどまります。私たちはあなたのデータを受け取るサーバーを一切運用していません。LinkHQ がネットワークを使う唯一の場面は、リンク自身のメタデータを取得するときで、以下に説明します。

## どのデータが集められるか

**ありません。** LinkHQ にはユーザーアカウントも、解析プラットフォームも、広告 SDK も、いかなる種類の追跡のしくみもありません。私たちは個人情報を集めも、保存も、送信もしません。

## アプリがデータをローカルで使う方法

### 保存したリンク

あなたが保存したリンクは、その題名、メモ、タグ、キーワード、ソース、お気に入り、開封状態とともに、あなたの端末だけに、共有アプリコンテナ内に保存されます。本体アプリとその共有拡張が同一の真実の情報源を読めるようにするためです。これらはアップロードされません。

### 共有シートからの取り込み

リンクを LinkHQ に共有すると、共有拡張が共有された URL、または共有テキスト内のリンクを読み取り、保存できるようにします。これはあなたの端末上で起こります。その共有に関する内容が、私たちの管理するサーバーへ送られることはありません。

### 端末内でのキーワード抽出

リンクを保存すると、その内容を表すいくつかのキーワードがあなたの端末上で抽出され、検索と絞り込みに使われます。これは Apple の端末内自然言語フレームワークを使ってローカルで動きます。このためにテキストがどこかへ送られることはありません。

## 唯一のネットワーク用途：リンクごとのメタデータ取得

むき出しの URL ではなく、リンクの本当の題名とプレビュー画像を表示するため、LinkHQ はリンク保存時にリンクごとのメタデータ取得を行い、取得が終わる前に保存されたリンクを補うため、アプリ内でもう一度行うことがあります。

- リクエストは **各リンク自身のサイト**、または **そのプラットフォームの oEmbed エンドポイント**（たとえば YouTube、TikTok、X）へ送られます。これはそのリンクに対してあなたのブラウザが到達するのと同じ宛先です。
- 読み取られるのは題名、説明、サイトのキーワード、プレビュー画像の URL だけです。保存されるのは画像の URL だけで、画像そのものは決して保存されません。プレビュー画像は表示時にサイトから読み込まれます。
- これらのリクエストは私たちが運用するサーバーへは送られず、アカウントや識別子も伴いません。そもそも存在しないからです。
- **あなたのライブラリはアップロードされません。** 取得は単一リンクの公開ページに関するものであり、あなたのコレクションに関するものではありません。

サイトに到達できない取得は、たとえばオフラインのとき、題名やサムネイルを次回起動時の補完に回すだけです。

## 権限

LinkHQ は端末の機微な権限を一切要求しません。

| 権限 | 状態 |
|------------|--------|
| **マイク** | 要求しない |
| **カメラ** | 要求しない |
| **連絡先** | 要求しない |
| **写真** | 要求しない |
| **ヘルスデータ** | 要求しない |
| **位置情報** | 要求しない |

共有シートからリンクを保存し、元の場所で開き直すのに、これらの権限は一切不要です。

## 第三者サービス

LinkHQ は第三者の解析、広告、追跡サービスを一切組み込みません。メタデータ取得は各リンク自身のサイト、またはそのプラットフォームの公開 oEmbed エンドポイントへ直接問い合わせ、キーワード抽出は Apple の端末内フレームワークを使い、あなたの端末上で OS の一部として動きます。

## データの共有

私たちはあなたのデータを誰にも売らず、貸さず、ライセンスせず、共有しません。LinkHQ は、あなたのライブラリ、メモ、タグ、キーワードを送信するネットワークトラフィックを発生させません。

## データの保持と削除

私たちはサーバーにデータを保存しないため、私たちの側で保持したり削除したりするものはありません。あなたの端末上のすべて、保存したリンクとそのあらゆる詳細は、アプリを削除した瞬間に取り除かれます。設定にはライブラリをその場で空にする「すべて削除」操作もあります。

## あなたの権利

私たちは何も集めないため、私たちの側にアクセス、訂正、ポータビリティ、消去の対象となる個人データはありません。アプリを管理または削除することで、ローカルに保存されたすべてをあなたが完全に管理できます。

## 子どものプライバシー

LinkHQ は、13 歳未満（またはあなたの法域で適用される年齢）の子どもを含め、誰からも情報を集めません。個人データを一切収集しないため、本アプリはあらゆる年齢の利用者にとって安全です。

## 国際的な利用者

LinkHQ は個人データを集めないため、個人情報の国境を越えた移転は発生しません。リンクごとのメタデータ取得は、あなたが保存したリンクをホストしているサイトに到達します。

## 本ポリシーの変更

本ポリシーを更新する場合、改訂版を新しい発効日とともにここに掲載します。更新後に本アプリを使い続けることは、改訂されたポリシーへの同意を意味します。
