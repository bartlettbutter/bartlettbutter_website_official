# 다시 돌아올 가치가 있는 것을 간직하세요.

LinkHQ는 다시 찾고 싶은 링크를 위한 조용한 공간입니다. 동영상이나 게시물, 페이지를 친구에게 보내듯 공유하면 LinkHQ가 링크를 담아 실제 제목과 키워드, 썸네일을 채워 준비해 둡니다. 나중에 탭하면 원래 앱이 그 동영상이나 게시물을 출처에서 다시 엽니다. 라이브러리는 기기에 남고 절대 업로드되지 않습니다.

    <h2 id="lk-why-title" class="marketing-section-title">다시 돌아올 생각인 링크를 위한 차분한 아카이브.</h2>
    <p class="marketing-section-intro">LinkHQ는 공유한 링크를 정말로 검색할 수 있는 라이브러리로 바꿉니다. 그래서 저장한 게시물을 다시 찾기 쉽고, 출처 앱까지는 탭 한 번 거리입니다.</p>
  </div>
  <div class="marketing-card-grid marketing-card-grid--two">
    <article class="marketing-card marketing-card--featured">
      <h3>어떤 앱에서든 담기</h3>
      <p>공유 확장이 시스템 공유 시트에 LinkHQ를 더해 주어, 발견한 바로 그곳에서 링크나 공유된 텍스트를 저장할 수 있습니다.</p>
      <ul class="marketing-list">
        <li>하나의 웹 URL, 또는 공유된 텍스트 안의 링크를 저장</li>
        <li>편집기가 임시 제목과 함께 곧바로 열립니다</li>
        <li>저장 전에 제목, 출처, 메모, 태그, 키워드를 조정</li>
      </ul>
    </article>
    <article class="marketing-card">
      <h3>제목, 썸네일, 키워드 자동</h3>
      <p>동영상이나 게시물, 페이지의 실제 제목을 가져와 벌거벗은 URL 대신 보여주며, 미리보기 이미지와 몇 개의 키워드도 함께 둡니다.</p>
      <ul class="marketing-list">
        <li>제목은 oEmbed 또는 페이지 자체의 메타데이터에서</li>
        <li>썸네일은 먼저 플랫폼 미리보기, 없으면 페이지 이미지</li>
        <li>키워드는 기기에서 추출해 검색과 필터링에 사용</li>
      </ul>
    </article>
    <article class="marketing-card">
      <h3>출처에서 다시 열기</h3>
      <p>Open Original을 탭하면 LinkHQ가 저장한 URL을 iOS에 넘기고, iOS는 그 앱이 설치되어 있을 때 해당 앱으로 연결합니다.</p>
      <ul class="marketing-list">
        <li>YouTube 링크는 YouTube 앱에서 다시 열립니다</li>
        <li>한 번도 다시 열지 않은 링크에는 점과 Unopened 필터가 있습니다</li>
        <li>Open Original이 링크를 열람함으로 표시해 줍니다</li>
      </ul>
    </article>
    <article class="marketing-card">
      <h3>기본적으로 비공개</h3>
      <p>라이브러리는 기기에만 저장되고 절대 업로드되지 않습니다. 네트워크는 저장할 때 링크별 메타데이터 조회에만 쓰입니다.</p>
      <ul class="marketing-list">
        <li>계정도, 분석도, 광고도 없음</li>
        <li>메타데이터 조회는 각 링크 자신의 사이트나 oEmbed 엔드포인트로</li>
        <li>앱을 삭제하면 라이브러리도 함께 사라집니다</li>
      </ul>
    </article>
