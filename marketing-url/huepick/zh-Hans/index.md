# 用不同的方式看色彩。

拍摄任何激发您灵感的事物。Huepick立即揭示其中隐藏的调色板，并为您提供创意工具，用它做出美丽的作品。完全免费，完全私密。

## 您真正能用Huepick做什么

- **几秒内找到完美调色板。** 将相机对准日落、壁画、布料样本 — Huepick提取出主色调，构建您可以立即使用的和谐调色板。不再需要目测十六进制代码或猜测什么搭配得好。
- **获得为您的项目设计的调色板。** 无论您是在装饰房间、搭配服装、选择妆容色号还是设计界面，Huepick都会生成带有标注色彩角色的调色板，契合您的场景。
- **将您的照片转化为艺术。** 五种创意工具 — 隔离、双色调、像素化、模糊和故障 — 让您用自己调色板中的色彩将任何照片变成可分享的作品。
- **保持一切私密和离线。** 您的照片永远不会离开您的设备。无需注册，无云端上传，无追踪。随处可用，即使没有Wi-Fi。

## 工作原理

1. **拍摄或选择照片** — 无需账户，无需设置
2. **查看您的调色板** — 立即提取多达12种主色
3. **选择一种风格** — 从6种色彩和谐类型和5种现实场景中选择
4. **玩转** — 用为您的调色板量身定制的创意工具转换您的照片
5. **保存和分享** — 导出调色板、下载创作，或直接分享

## 内含功能

**分析** — 提取颜色，跨六种和谐类型生成调色板，并通过详细的视觉分解探索您的调色板。应用甚至会推荐哪些创意工具最适合您的特定照片。

**Playground** — 转换图像的五种工具：
- *隔离* — 突出特定颜色，其余变为单色
- *双色调* — 将您的图像重新映射为两种大胆的色调
- *像素化* — 转换为几何像素艺术
- *模糊* — 添加柔和、梦幻的焦点
- *故障* — 应用数字失真，营造前卫外观

**画廊** — 您保存的每个创作都在这里。随时重新编辑、下载或分享。
