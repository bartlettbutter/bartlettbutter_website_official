**生效日期：** 2026年7月22日

Journeyfolio（"本应用"）由Bartlett Butter开发。本政策说明本应用如何处理您的信息。简短的答案是：我们不收集任何信息。

## 概览

| 问题 | 回答 |
|------|------|
| 你们收集个人数据吗？ | 否 |
| 有账户或登录吗？ | 否 |
| 有追踪或分析吗？ | 否 |
| 有广告吗？ | 否 |
| 我的数据会被出售或共享吗？ | 否 |
| 该应用会访问我的GPS位置吗？ | 否 |
| 该应用对儿童安全吗？ | 是 |

## 我们收集的数据

**无。** Journeyfolio不会向我们的服务器收集、存储或传输任何个人数据。没有用户账户、没有分析SDK、没有广告框架，也没有任何形式的追踪。

## 您的行程数据

您创建的所有信息（包括目的地、日期、活动、航班号、酒店详情、附加文档和备注）都**仅存储在您的设备本地**。除非本应用与第三方服务通信（如下所述）以获取您明确请求的内容，否则这些数据永远不会离开您的设备。

## 订阅和购买

Journeyfolio提供完全通过Apple App Store处理的可选自动续订订阅。我们不会收到或访问您的付款信息。所有计费和订阅管理均由Apple根据其[隐私政策](https://www.apple.com/legal/privacy/)处理。

## 位置数据

Journeyfolio**不会**访问您设备的GPS或追踪您的实际位置。

当您添加目的地或搜索地点时，您的搜索查询会发送到Apple的服务器以返回结果。城市名称会发送给Apple进行地理编码和天气数据。国家代码会发送给公共假日服务以获取假日信息。不收集或传输其他任何位置数据。

## 设备权限

| 权限 | 何时请求 | 目的 | 数据是否离开设备？ |
|------|---------|------|-------------------|
| 相机 | 当您拍摄文档时 | 将旅行文档附加到活动 | 否 — 通过OCR在设备上处理 |
| 照片库 | 当您导入现有图像时 | 将保存的图像附加到活动 | 否 |

这两项权限都是可选的。没有它们本应用也能完全运行。任何图像都不会上传到外部服务器。

## 第三方服务

本应用连接以下服务仅用于显示您请求的内容。不发送任何个人数据或设备标识符，仅发送完成每个请求所需的最少信息。

| 服务 | 目的 | 发送的数据 | 隐私信息 |
|------|------|-----------|----------|
| Apple天气和地图 | 天气预报、位置搜索、时区解析 | 城市名称、坐标 | [Apple隐私政策](https://www.apple.com/legal/privacy/) |
| 第三方天气服务 | 备用天气数据 | 城市名称 | 无 |
| 航班数据服务 | 航班时刻验证和实时状态 | 航班号、日期 | 无 |
| 公共假日服务 | 公共假日信息 | 国家代码、年份 | 无 |

## 数据共享

我们不向任何第三方出售、出租、许可或共享您的数据。本应用发出的唯一网络通信是上述服务请求。

## 数据保留和删除

您的行程数据会保留在您的设备上，直到您选择删除它，无论是在应用内还是通过卸载。卸载会永久移除所有存储的数据。没有云备份或同步。

**您始终掌控。** 随时在应用内向左滑动即可删除任何行程或活动。

## 您的权利

由于Journeyfolio将所有数据存储在本地，并且我们这边不收集任何内容，因此您已经完全掌控您的信息。您可以随时直接在应用内查看、编辑或删除您的数据，无需向我们请求。

## 儿童隐私

Journeyfolio不会在知情的情况下收集任何人的信息，包括13岁以下的儿童（或您所在司法管辖区适用的最低年龄）。由于本应用完全不收集个人数据，因此对所有年龄的用户都是安全的。

## 国际用户

由于不收集任何个人信息，因此不会发生个人信息的跨境传输。向第三方服务发出的网络请求仅包含与目的地相关的查询（城市名称、航班号、国家代码），无论您身处何地，都不包含任何个人数据或设备标识符。

## 本政策的变更

如果我们更新此政策，修订版本将在此页面发布，并附有新的生效日期。重大变更将在页面顶部注明。更新后继续使用该应用即表示接受修订后的政策。
