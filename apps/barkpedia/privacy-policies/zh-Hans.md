**生效日期：** 2026年4月11日

Barkpedia（"本应用"）是一款免费的iOS应用程序，可通过照片识别狗的品种。您的隐私是我们构建此应用的核心理念。以下是您的信息被处理方式的详细说明。

## 简要版本

| 问题 | 回答 |
|------|------|
| 你们收集个人数据吗？ | 否 |
| 我的照片会离开我的设备吗？ | 否 |
| 有账户或登录吗？ | 否 |
| 有追踪或分析吗？ | 否 |
| 有广告吗？ | 否 |
| 我的数据会被出售或共享吗？ | 否 |
| 儿童可以安全使用该应用吗？ | 是 |

## 我们收集的数据

**无。** 我们不收集、存储或传输任何个人数据。本应用不包含用户账户、分析SDK、广告框架或任何第三方追踪工具。

## 您的照片如何被处理

本应用请求相机和照片库权限仅用于让您拍摄或选择狗的图片进行品种识别。您拍摄或选择的照片完全在您的设备上使用本地智能进行分析。**您的照片永远不会上传到任何服务器。**

## 设备上存储的内容

- **收藏夹** — 您选择保存的品种扫描结果仅存储在您的设备本地。
- **探索数据** — 品种搜索索引和原产国地图数据已捆绑在应用本身内。
- **地图渲染** — 交互式世界地图使用Apple地图（MapKit），完全在您的设备上本地渲染。

这些数据均不会对外传输。当您删除应用时，所有这些数据都会自动移除。

## 网络请求

本应用连接以下服务仅用于获取显示内容（品种资料、图片和游戏问题）：

| 服务 | 目的 | 发送的个人数据 |
|------|------|---------------|
| The Dog API | 品种信息（性格、数据、历史） | 无 |
| dogapi.dog | 额外的品种信息和趣味问答的狗狗事实 | 无 |
| Dog CEO API | 品种图片和测验照片 | 无 |
| Wikipedia | 品种参考图片 | 无 |

这些是标准的内容获取请求。任何请求中都不包含个人数据、设备标识符或追踪信息。

## 数据共享

我们不向第三方出售、出租或共享任何用户数据。没有用户数据可供共享。

## 我们请求的权限

| 权限 | 我们为什么请求 | 是否必需？ |
|------|--------------|-----------|
| 相机 | 拍摄狗的照片以进行品种识别 | 可选 — 您可以使用照片库 |
| 照片库 | 选择现有照片以进行品种识别 | 可选 — 您可以使用相机 |

**仅此而已。** 本应用不请求或访问位置、通讯录、麦克风、蓝牙、追踪（ATT）、通知或任何其他敏感权限。

## 数据保留和删除

由于我们不在服务器上收集任何数据，因此我们这边没有需要保留或删除的内容。所有本地存储的数据 — 包括收藏夹和扫描历史 — 会在您从设备上删除应用时自动移除。

## 您的权利

由于Barkpedia不收集个人数据，我们的系统中没有用户数据可供访问、导出、更正或删除。您对设备上本地存储的一切保持完全控制。

## 儿童隐私

本应用不收集任何人的信息，包括13岁以下的儿童（或您所在司法管辖区适用的年龄）。由于不收集个人数据，本应用对所有年龄的用户都是安全的，并符合COPPA要求。

## 国际用户

由于Barkpedia不收集个人数据，因此不会发生个人信息的跨境传输。向第三方服务发出的内容获取请求（品种信息、图片）不包含任何个人数据或设备标识符，无论您身处何地。

## 本政策的变更

如果我们更新此政策，修订版本将在此页面发布，并附有更新的生效日期。更新后继续使用该应用即表示接受修订后的政策。
