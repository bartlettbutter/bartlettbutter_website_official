**Fecha de vigencia:** 11 de abril de 2026

Barkpedia ("la Aplicación") es una aplicación iOS gratuita que identifica razas de perros a partir de fotos. Tu privacidad es fundamental en el diseño de esta aplicación. Aquí explicamos exactamente cómo se maneja tu información.

## Versión Resumida

| Pregunta | Respuesta |
|----------|-----------|
| ¿Recopilan datos personales? | No |
| ¿Mis fotos salen de mi dispositivo? | No |
| ¿Hay cuentas o inicios de sesión? | No |
| ¿Hay rastreo o analíticas? | No |
| ¿Hay anuncios? | No |
| ¿Se venden o comparten mis datos? | No |
| ¿Los niños pueden usar la aplicación de forma segura? | Sí |

## Qué Datos Recopilamos

**Ninguno.** No recopilamos, almacenamos ni transmitimos ningún dato personal. La Aplicación no contiene cuentas de usuario, SDKs de analíticas, frameworks publicitarios ni herramientas de rastreo de terceros.

## Cómo se Manejan tus Fotos

La Aplicación solicita permisos de cámara y biblioteca de fotos únicamente para permitirte fotografiar o seleccionar imágenes de perros para la identificación de raza. Las fotos que tomas o seleccionas se analizan completamente en tu dispositivo utilizando inteligencia en el dispositivo. **Tus fotos nunca se suben a ningún servidor.**

## Qué se Almacena en tu Dispositivo

- **Favoritos** — Los resultados de escaneo de razas que eliges guardar se almacenan únicamente en tu dispositivo.
- **Datos de Explorar** — El índice de búsqueda de razas y los datos del mapa de país de origen están incluidos dentro de la propia aplicación.
- **Renderizado del mapa** — El mapa mundial interactivo usa Apple Maps (MapKit), que se renderiza localmente en tu dispositivo.

Ninguno de estos datos se transmite externamente. Todos se eliminan automáticamente cuando desinstalas la Aplicación.

## Solicitudes de Red

La Aplicación se conecta a los siguientes servicios únicamente para obtener contenido para mostrar (perfiles de razas, imágenes y preguntas de juegos):

| Servicio | Propósito | Datos Personales Enviados |
|----------|-----------|---------------------------|
| The Dog API | Información de razas (temperamento, estadísticas, historia) | Ninguno |
| dogapi.dog | Información adicional de razas y datos curiosos de perros para la trivia | Ninguno |
| Dog CEO API | Imágenes de razas y fotos de quiz | Ninguno |
| Wikipedia | Imágenes de referencia de razas | Ninguno |

Estas son solicitudes estándar de obtención de contenido. No se incluyen datos personales, identificadores de dispositivo ni información de rastreo en ninguna solicitud.

## Compartición de Datos

No vendemos, alquilamos ni compartimos ningún dato de usuario con terceros. No hay datos de usuario que compartir.

## Permisos que Solicitamos

| Permiso | Por Qué lo Solicitamos | ¿Requerido? |
|---------|----------------------|-------------|
| Cámara | Para fotografiar perros para la identificación de raza | Opcional — puedes usar tu biblioteca de fotos |
| Biblioteca de Fotos | Para seleccionar fotos existentes para la identificación de raza | Opcional — puedes usar la cámara |

**Eso es todo.** La Aplicación no solicita ni accede a ubicación, contactos, micrófono, Bluetooth, rastreo (ATT), notificaciones ni ningún otro permiso sensible.

## Retención y Eliminación de Datos

Ya que no recopilamos datos en nuestros servidores, no hay nada que retener o eliminar de nuestro lado. Todos los datos almacenados localmente — incluidos los favoritos y el historial de escaneos — se eliminan automáticamente cuando desinstalas la Aplicación de tu dispositivo.

## Tus Derechos

Dado que Barkpedia no recopila datos personales, no hay datos de usuario que acceder, exportar, corregir o eliminar de nuestros sistemas. Mantienes el control total sobre todo lo almacenado localmente en tu dispositivo.

## Privacidad de los Niños

La Aplicación no recopila información de nadie, incluidos los niños menores de 13 años (o la edad aplicable en tu jurisdicción). Dado que no se recopilan datos personales, la Aplicación es segura para usuarios de todas las edades y cumple con los requisitos de COPPA.

## Usuarios Internacionales

Dado que Barkpedia no recopila datos personales, no se produce ninguna transferencia transfronteriza de información personal. Las solicitudes de contenido a servicios de terceros (información de razas, imágenes) no contienen datos personales ni identificadores de dispositivo, independientemente de tu ubicación.

## Cambios en Esta Política

Si actualizamos esta política, la versión revisada se publicará en esta página con una fecha de vigencia actualizada. El uso continuado de la aplicación después de una actualización constituye la aceptación de la política revisada.
