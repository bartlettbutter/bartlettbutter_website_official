**生效日期：** 2026年6月13日

Nekopedia（"本應用"）是一款免費的iOS應用程式，可透過照片識別貓的品種。隱私並非事後才考慮的事項，而是本應用從第一天起的構建方式。本政策以通俗易懂的語言說明您的資訊如何被處理。簡而言之：它始終留在您這裡。

## 簡要版本

| 問題 | 回答 |
|------|------|
| 你們收集個人資料嗎？ | 否 |
| 我的照片會離開我的裝置嗎？ | 否 |
| 有賬戶或登入嗎？ | 否 |
| 有追蹤或分析嗎？ | 否 |
| 有廣告嗎？ | 否 |
| 我的資料會被出售或共享嗎？ | 否 |
| 兒童可以安全使用該應用嗎？ | 是 |

您的照片完全在您的裝置上處理，永遠不會離開裝置。品種識別完全離線執行。本應用發出的唯一網路請求是獲取品種資訊、圖片和遊戲內容以供顯示。

## 我們收集的資料

無。我們不收集、儲存或傳輸任何個人資料。本應用不包含使用者賬戶、分析SDK、廣告框架或任何第三方追蹤工具。

## 照片和相機/相簿訪問

本應用請求相機和照片庫許可權僅用於讓您拍攝或選擇貓的圖片進行品種識別。您拍攝或選擇的照片完全在您的裝置上使用本地智慧進行分析。您的照片永遠不會上傳到任何伺服器。

## 本地儲存的資料

您儲存到收藏夾的品種掃描結果僅儲存在您的裝置上。這些資料永遠不會對外傳輸，可以隨時透過刪除應用來移除。

## 第三方服務

本應用僅為獲取顯示內容而連線第三方貓咪參考服務：品種資訊（性格、資料、歷史）、品種和測驗圖片以及趣味知識。

**任何請求中都不包含任何個人資料、裝置識別符號或追蹤資訊。** 沒有任何請求會識別您的身份，也從不傳輸任何分析或廣告資料。

## 資料共享

我們不向第三方出售、出租或共享任何使用者資料。沒有資料可供共享。

## 許可權

| 許可權 | 我們為什麼請求 | 是否必需？ |
|------|--------------|-----------|
| 相機 | 拍攝貓的照片以進行品種識別 | 可選（您可以使用照片庫） |
| 照片庫 | 選擇現有照片以進行品種識別 | 可選（您可以使用相機） |

不請求或訪問其他許可權。本應用不使用位置、通訊錄、麥克風、追蹤、通知或任何其他敏感訪問。

## 資料保留和刪除

由於我們不在伺服器上收集任何資料，因此我們這邊沒有需要保留或刪除的內容。所有本地儲存的資料，包括收藏夾和掃描歷史，會在您從裝置上刪除應用時自動移除。

## 您的權利

由於Nekopedia不收集個人資料，我們的系統中沒有使用者資料可供訪問、匯出、更正或刪除。您對裝置上本地儲存的所有資料保持完全控制。

## 兒童隱私

本應用不收集任何人的資訊，包括13歲以下的兒童（或您所在司法管轄區適用的年齡）。由於不收集個人資料，本應用對所有年齡的使用者都是安全的，並符合COPPA要求。

## 國際使用者

由於Nekopedia不收集個人資料，因此不會發生個人資訊的跨境傳輸。向第三方服務發出的內容獲取請求（品種資訊、圖片、遊戲內容）不包含任何個人資料或裝置識別符號，無論您身處何地。

## 本政策的變更

如果我們更新此政策，修訂版本將在此頁面釋出，並附有更新的生效日期。更新後繼續使用該應用即表示接受修訂後的政策。
