**시행일:** 2026년 4월 25일

ETFWise("본 앱")는 실시간 시장 데이터와 기기 내 AI 분석을 통해 매일 ETF 추천을 제공하는 무료 iOS 애플리케이션입니다. 여러분의 개인정보 보호는 저희가 이 앱을 만든 방식의 근간입니다. 여기에서 여러분의 정보가 정확히 어떻게 처리되는지 설명합니다.

## 요약본

| 질문 | 답변 |
|------|------|
| 개인정보를 수집하나요? | 아니요 |
| 계정이나 로그인이 있나요? | 아니요 |
| 추적이나 분석이 있나요? | 아니요 |
| 광고가 있나요? | 아니요 |
| 제 데이터가 판매되거나 공유되나요? | 아니요 |
| AI 분석이 제 기기를 벗어나나요? | 아니요 |
| 어린이가 앱을 안전하게 사용할 수 있나요? | 예 |

외부로 전송되는 유일한 데이터는 시장 데이터를 가져오기 위한 ETF 티커 심볼입니다. 여러분의 Finnhub API 키는 기기에 안전하게 저장되며 Finnhub에만 전송됩니다.

## 저희가 수집하는 데이터

없습니다. 저희는 어떠한 개인정보도 서버에 수집, 저장, 전송하지 않습니다. ETFWise에는 사용자 계정, 사용 분석, 광고 또는 추적 프레임워크가 없습니다.

## 기기에 남는 내용

모든 앱 데이터는 여러분의 기기에 로컬로 저장됩니다.

- 매일의 ETF 추천 및 캐시된 시장 가격
- 뉴스 감성 점수 및 AI가 생성한 분석
- 여러분의 Finnhub API 키(기기 내 저장소에 안전하게 저장)
- 다운로드된 AI 모델 파일

이 데이터는 매일 갱신되며 외부 서버에 업로드되지 않습니다.

## 타사 서비스

ETFWise는 표시용 시장 데이터를 가져오는 목적으로만 금융 데이터 제공업체에 연결합니다. 전송되는 유일한 정보는 ETF 티커 심볼과 날짜 범위입니다. 개인정보, 기기 식별자, 위치 정보는 전송되지 않습니다.

| 서비스 | 제공 내용 | 전송되는 데이터 | 개인정보 정보 |
|--------|-----------|----------------|--------------|
| Finnhub | 실시간 시세, 뉴스, 감성, 애널리스트 데이터 | 티커 심볼, 날짜 범위, 여러분의 API 키 | [개인정보 처리방침](https://finnhub.io/privacy-policy) |
| Yahoo Finance | 펀드 규모, 보유 종목, 섹터 비중, 성과 | 티커 심볼 | [개인정보 처리방침](https://legal.yahoo.com/us/en/yahoo/privacy/index.html) |
| Polymarket | 예측 시장 확률 | 공개 이벤트 데이터만 | [개인정보 처리방침](https://polymarket.com/privacy) |
| HuggingFace | 일회성 다운로드를 위한 AI 모델 파일 호스팅 | 모델 파일 다운로드만 | [개인정보 처리방침](https://huggingface.co/privacy) |

## 기기 내 AI 처리

AI 모델은 전적으로 여러분의 기기에서 실행됩니다. 강세 시나리오, 위험 시나리오, 펀드 설명을 포함한 모든 추론이 로컬에서 이루어집니다. AI 처리를 위해 프롬프트, 입력 또는 출력이 외부 서버로 전송되지 않습니다.

## API 키 보안

Finnhub API 키를 입력하면 해당 키는 여러분의 기기에 안전하게 저장되며 인증을 위해 Finnhub의 API에만 전송됩니다. 다른 어디로도 전송되지 않으며 다른 어떤 당사자와도 공유되지 않습니다.

## 데이터 공유

저희는 여러분의 데이터를 어떤 제3자에게도 판매, 대여, 공유하지 않습니다. 데이터 공유 계약, 광고 파트너, 분석 제공업체가 없습니다.

## 권한

ETFWise는 여러분의 카메라, 위치, 연락처, 마이크, 건강 데이터, 사진 또는 앱 추적 투명성에 대한 접근을 요청하지 않습니다. 앱을 사용하는 데 특별한 권한이 필요하지 않습니다.

## 데이터 보존 및 삭제

저희는 서버에서 개인정보를 수집하지 않으므로 저희 측에서 보존하거나 삭제할 것이 없습니다. 추천, 캐시된 가격, AI 분석, 여러분의 API 키를 포함한 모든 로컬 저장 데이터는 기기에서 앱을 삭제하면 영구적으로 제거됩니다.

## 여러분의 권리

ETFWise는 어떤 서버에도 개인정보를 수집하거나 저장하지 않으므로 저희 시스템에서 액세스, 수정, 내보내기 또는 삭제할 개인정보가 없습니다. 여러분은 기기에서 앱을 관리하거나 제거하여 모든 로컬 저장 데이터에 대한 완전한 통제권을 유지합니다.

## 아동의 개인정보 보호

ETFWise는 13세 미만의 어린이(또는 해당 관할 지역에서 적용되는 연령)를 포함하여 누구로부터도 고의로 개인정보를 수집하지 않습니다. 앱이 어떠한 개인정보도 수집하지 않으므로 COPPA 요건을 준수합니다.

## 국제 사용자

ETFWise는 개인정보를 수집하지 않으므로 개인정보의 국경 간 이전이 발생하지 않습니다. 금융 데이터 제공업체로의 티커 심볼 요청에는 위치에 관계없이 개인정보나 기기 식별자가 포함되지 않습니다.
