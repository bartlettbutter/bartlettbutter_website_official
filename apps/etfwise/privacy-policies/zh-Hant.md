**生效日期：** 2026年10月28日

ETFWise（"本應用"）是一款可免費下載、並提供可選進階版訂閱的iOS應用程式，透過市場資料和裝置端即時分析提供每日ETF精選。您的隱私是我們構建此應用的核心理念。以下是您的資訊被處理方式的詳細說明。

## 簡要版本

| 問題 | 回答 |
|------|------|
| 你們收集個人資料嗎？ | 否 |
| 有賬戶或登入嗎？ | 否 |
| 有追蹤或分析嗎？ | 否 |
| 有廣告嗎？ | 否 |
| 我的資料會被出售或共享嗎？ | 否 |
| 分析會離開我的裝置嗎？ | 否 |
| 你們會收到我的付款資訊嗎？ | 否。進階版購買由Apple處理 |
| 兒童可以安全使用該應用嗎？ | 是 |

本應用向金融資料提供商傳送的唯一資料是用於獲取市場資料的ETF程式碼。進階版購買由Apple處理。

## 我們收集的資料

無。我們不會向伺服器收集、儲存或傳輸任何個人資訊。ETFWise沒有使用者賬戶、沒有使用分析，也沒有廣告或追蹤框架。

## 保留在您裝置上的內容

所有應用資料都儲存在您的裝置本地：

- 每日ETF推薦和快取的市場價格
- 新聞情緒評分和生成的分析
- 您的設定，例如外觀和業績時間段
- 您的篩選器規則和符合模式

市場資料會定期重新整理，以上資料均不會上傳到外部伺服器。

## 第三方服務

ETFWise連線第三方金融資料提供商僅用於獲取市場資料以供顯示。

| 傳送的資料 | 包含的個人資料 |
|---|---|
| ETF程式碼和日期範圍 | 無 |

任何請求中都不包含裝置識別符號、位置或追蹤資訊。

## 進階版訂閱

ETFWise提供可解鎖篩選器的可選自動續訂進階版訂閱。購買、計費、續訂、恢復和取消均由Apple透過您的Apple帳號全權處理。我們不會收到您的姓名、付款資訊或Apple帳號資訊，本應用也沒有自己的帳戶體系。本應用使用Apple的購買記錄在您的裝置上檢查訂閱狀態。您可以隨時在設定 > Apple帳號 > 訂閱項目中管理或取消訂閱。Apple如何處理您的資料，請參閱[Apple隱私政策](https://www.apple.com/legal/privacy/)。

## 裝置端分析

看漲理由、風險理由和基金描述完全在您的裝置上根據已為每個ETF獲取的市場資料生成。此分析不涉及任何單獨下載，也不涉及外部伺服器。與之相關的任何內容都不會離開您的裝置。

## 資料共享

我們不向任何第三方出售、出租或共享您的資料。我們沒有資料共享協議、沒有廣告合作伙伴，也沒有分析提供商。

## 許可權

ETFWise不請求訪問您的相機、位置、通訊錄、麥克風、健康資料、照片或應用追蹤透明度。使用本應用無需任何特殊許可權。

## 資料保留和刪除

由於我們不在伺服器上收集任何個人資料，因此我們這邊沒有需要保留或刪除的內容。所有本地儲存的資料，包括推薦、快取價格、設定、篩選器規則和生成的分析，都會在您從裝置上刪除應用時被永久移除。刪除應用不會取消進階版訂閱；請在您的Apple帳號設定中管理訂閱。

## 您的權利

由於ETFWise不在任何伺服器上收集或儲存個人資料，我們的系統中沒有個人資料可供訪問、更正、匯出或刪除。您透過管理或移除裝置上的應用來對所有本地儲存的資料保持完全控制。

## 兒童隱私

ETFWise不會在知情的情況下收集任何人的個人資訊，包括13歲以下的兒童（或您所在司法管轄區適用的年齡）。由於本應用完全不收集個人資料，因此符合COPPA要求。

## 國際使用者

由於ETFWise不收集個人資料，因此不會發生個人資訊的跨境傳輸。向金融資料提供商發出的程式碼請求不包含任何個人資料或裝置識別符號，無論您身處何地。

## 本政策的變更

如果我們更新此政策，修訂版本將在此頁面釋出，並附有更新的生效日期。更新後繼續使用該應用即表示接受修訂後的政策。
