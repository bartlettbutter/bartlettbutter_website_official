# どんなことでお手伝いできますか？

LinkHQ を存分に活用していただきたいと考えています。思ったように動かないことや疑問があれば、たいていは下に答えがあります。見つからなければ、お問い合わせください。お手伝いします。

## はじめに

### アプリの設定はどうしますか？

LinkHQ を開くだけです。アカウントも登録も不要です。初回起動時に一度だけ表示される歓迎画面が、短い三つの手順でしくみを説明し、ライブラリに入ればすぐにリンクの保存を始められます。

### リンクはどう保存しますか？

ほかのアプリで残したいものを見つけ、共有をタップし、共有シートで LinkHQ を選びます。友だちに送るのと同じ感覚です。エディタが仮のタイトルと共にすぐ開きます。必要ならタイトル、ソース、メモ、タグ、キーワードを調整し、保存をタップします。アプリの「リンクを追加」画面から手動で追加することもできます。

### タイトル、サムネイル、キーワードはどうなりますか？

リンクを保存すると、LinkHQ がネットワーク越しに本当のタイトルとプレビュー画像を取得し、端末内でいくつかのキーワードを抽出します。すでにタイトルを編集していない限り、仮のタイトルは本当のタイトルに置き換わり、サムネイルは分かり次第表示されます。これが終わる前に保存したリンクは、タイトル、キーワード、サムネイルをあとからアプリ内で受け取ります。

### リンクをどう見つけ直しますか？

タイトル、URL、メモ、タグ、キーワードを横断して検索でき、入力中に一致するキーワードが提案されます。ソース、キーワード、お気に入り、未開封のリンクでライブラリを絞り込むこともでき、気になるものはお気に入りに登録できます。

### リンクを元の場所でどう開き直しますか？

リンクを開いて Open Original をタップします。LinkHQ は保存した URL を iOS に渡し、該当アプリがインストールされていてその URL を要求していれば、そのアプリが開き直します。たとえば YouTube のリンクは YouTube アプリで開きます。Open Original はリンクを開封済みにも記録します。

## よくある質問

### LinkHQ は無料ですか？

はい。LinkHQ はダウンロードも利用も無料で、広告もアカウントもありません。

### LinkHQ はデータを集めますか？

いいえ。ユーザーアカウントも、解析も、追跡も、広告もありません。ライブラリは端末内だけに保存され、アップロードされません。ネットワークを使うのは、タイトル、サムネイル、キーワードを取得するリンクごとのメタデータ取得だけです。詳しくは全文の[プライバシーポリシー](https://www.bartlettbutter.com/linkhq/privacy/ja/)をご覧ください。

### LinkHQ はどのソースを認識しますか？

リンクはホストによって YouTube、RedNote、Bilibili、TikTok、Instagram、X、Web に自動分類されます。ソースはライブラリに表示するアイコンを決め、タイトルの取得方法を導きます。エディタでソースを手動で変更できます。

### 未開封のリンクとは何ですか？

LinkHQ から一度も開き直していないリンクには小さな点が付き、Unopened フィルタがそれらを一か所にまとめます。Open Original はリンクを開封済みにし、手動でリンクを開封済みや未開封にすることもできます。

### 重複の警告は何を意味しますか？

すでに保存済みのリンクを共有または追加すると、LinkHQ が最初にいつ、どのタイトルで保存したかを示します。再び保存することは引き続き可能で、警告はあなたが判断できるようにあるだけです。

### なぜサムネイルの代わりにソースアイコンが出るのですか？

一部のプラットフォームは期限切れになる署名を画像 URL に付け、別の一部は匿名の取得を拒むため、サムネイルは常に得られるとは限りません。プレビュー画像がないときは、ソースアイコンが代わりになります。コンテンツの閲覧にサインインが必要なサイトもあり、その場合タイトルはリンクと共に共有されたテキストからのみ得られます。

### LinkHQ は iPad で動きますか？

はい。通常幅の iPad ではライブラリが分割ビューになり、一覧がサイドバー、選んだリンクの詳細がその横に並び、ウィンドウのサイズ変更に合わせてレイアウトが組み直されます。どの iPhone も単一列のレイアウトを保ちます。

### LinkHQ は Dynamic Type に対応していますか？

はい。すべてのテキストがシステムの文字サイズ設定に従い、最大のアクセシビリティサイズまで対応します。既定サイズではレイアウトは変わりません。

## 権限

### LinkHQ に特別な権限は必要ですか？

いいえ。LinkHQ はマイク、カメラ、連絡先、写真、ヘルスデータ、位置情報を要求しません。共有シートからリンクを保存し、元の場所で開き直すのに、これらの権限は不要です。

### LinkHQ はなぜネットワークを使うのですか？

保存したリンクのメタデータを取得するためだけです。リンクを保存すると、その URL がリンク自身のサイト、またはそのプラットフォームの oEmbed エンドポイントへ送られ、タイトルとサムネイルを取得します。その後キーワード抽出が端末内で動きます。ライブラリ自体はアップロードされません。

## トラブルシューティング

### リンクに本当のタイトルが付かなかった

コンテンツの閲覧にサインインが必要なサイトもあり、その場合タイトルはリンクと共に共有されたテキストからのみ得られます。手動で貼り付けたリンクは、編集するまでホストをタイトルのままにします。各リンクは起動ごとに最多で一度だけ取得され、サイトに届かなかった取得は次回起動で再試行されるため、アプリを開き直すと欠けていたタイトルがしばしば埋まります。

### 保存したリンクがすぐ出てこない

アプリと共有拡張は、同じライブラリ上で別々のプロセスとして動きます。アプリがすでにバックグラウンドで動いている間に保存したリンクは、アプリを再起動するまで現れないことがあります。

### Open Original がアプリでなくブラウザを開いた

Open Original は保存した URL を iOS に渡します。該当アプリがインストールされ、その URL を要求しているときにだけ開き直します。そうでなければリンクはブラウザで開きます。

### サムネイルが出ない

サムネイルはキャッシュにないとき、サイトから読み込まれます。一部のプラットフォームは画像 URL を期限切れにしたり匿名の取得を拒んだりするため、そうしたリンクはソースアイコンを表示します。これはリンクの保存や開き直しには影響しません。

### 短縮リンク越しの重複が捕まらなかった

短縮リンク越しの一致は、短縮リンクが解決されたあとにだけ認識されます。これは共有シート、またはアプリのバックグラウンドの補完で起こります。アプリを開き直すと解決の機会が生まれます。

### アプリがクラッシュする

App Store の最新版を使っていることを確かめ、端末を再起動してください。クラッシュが続く場合は、端末の機種と iOS のバージョンを添えてメールでお知らせください。調査いたします。
