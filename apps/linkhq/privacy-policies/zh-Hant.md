**生效日期：** 2026年3月3日

LinkHQ（「本應用程式」）是一款面向 iPhone 和 iPad 的免費、僅存本機的連結封存應用程式。隱私是我們構建它的核心。本政策明確說明使用 LinkHQ 時涉及哪些資料，更重要的是，不涉及哪些資料。

## 簡要版

| 問題 | 回答 |
|----------|--------|
| 你們會收集個人資料嗎？ | 否 |
| 我的收藏庫會被傳送到你們的伺服器嗎？ | 否 |
| 有帳戶或登入嗎？ | 否 |
| 有追蹤或分析嗎？ | 否 |
| 有廣告嗎？ | 否 |
| 我的資料會被出售或共享嗎？ | 否 |
| 應用程式對兒童安全嗎？ | 是 |

你儲存的連結，以及它們的標題、備註、標籤和關鍵字，都留在你的裝置上。我們不營運任何接收你資料的伺服器。LinkHQ 唯一使用網路的時刻，是查詢連結自身的中繼資料，如下所述。

## 收集了哪些資料

**沒有。** LinkHQ 沒有使用者帳戶，沒有分析平台，沒有廣告 SDK，也沒有任何形式的追蹤機制。我們不收集、不儲存、也不傳輸個人資訊。

## 應用程式如何在本機使用資料

### 你儲存的連結

你儲存的連結，連同它們的標題、備註、標籤、關鍵字、來源、收藏狀態和開啟狀態，都只儲存在你的裝置上，位於一個共享的應用程式容器中，以便主應用程式和它的共享擴充功能讀取同一份資料來源。它們絕不會被上傳。

### 從共享選單擷取

當你把連結分享進 LinkHQ 時，共享擴充功能會讀取分享的網址，或分享文字中夾帶的連結，以便儲存。這發生在你的裝置上。關於此次分享的任何內容都不會被傳送到我們控制的任何伺服器。

### 裝置端關鍵字擷取

儲存連結時，會在你的裝置上擷取若干描述其內容的關鍵字，用於搜尋和篩選。這一過程使用 Apple 的裝置端自然語言框架在本機執行。為此不會向任何地方傳送任何文字。

## 唯一的網路用途：逐條連結的中繼資料查詢

為了顯示連結真正的標題和預覽圖，而不是一串裸網址，LinkHQ 會在儲存連結時執行一次逐條連結的中繼資料查詢，有時還會在應用程式中再查詢一次，以補齊那些在查詢完成前就被儲存的連結。

- 請求會發往**每個連結自己的網站**，或**該平台的 oEmbed 端點**（例如 YouTube、TikTok 或 X），與你的瀏覽器為該連結存取的目的地相同。
- 只讀取標題、描述、網站關鍵字和預覽圖網址。只儲存圖片網址，絕不儲存圖片本身；預覽圖在顯示時才從網站載入。
- 這些請求不會傳送到任何由我們營運的伺服器，並且不攜帶任何帳戶或識別碼，因為根本沒有。
- **你的收藏庫絕不會被上傳。** 查詢針對的是單一連結的公開頁面，而非你的整個收藏。

無法連上網站的查詢，例如在你離線時，只會把標題或縮圖留待下次啟動時補齊。

## 權限

LinkHQ 不請求任何敏感的裝置權限。

| 權限 | 狀態 |
|------------|--------|
| **麥克風** | 不請求 |
| **相機** | 不請求 |
| **通訊錄** | 不請求 |
| **照片** | 不請求 |
| **健康資料** | 不請求 |
| **位置** | 不請求 |

從共享選單儲存連結並在來源處重新開啟它們，都不需要上述任何權限。

## 第三方服務

LinkHQ 不整合任何第三方分析、廣告或追蹤服務。中繼資料查詢直接聯絡每個連結自己的網站或該平台的公開 oEmbed 端點，關鍵字擷取使用 Apple 的裝置端框架，作為作業系統的一部分在你的裝置上執行。

## 資料共享

我們不會向任何人出售、出租、授權或共享你的資料。LinkHQ 不會產生任何傳輸你的收藏庫、備註、標籤或關鍵字的網路流量。

## 資料保留與刪除

我們的伺服器上不儲存任何資料，因此我方無任何內容需要保留或刪除。你裝置上的一切，你儲存的連結及其所有詳情，都會在你刪除應用程式的那一刻移除。設定中還包含「全部刪除」操作，可就地清空你的收藏庫。

## 你的權利

由於我們什麼都不收集，我方不存在可供存取、更正、可攜或抹除的個人資料。透過管理或移除應用程式，你對所有本機儲存的內容擁有完全控制。

## 兒童隱私

LinkHQ 不會從任何人收集資訊，包括 13 歲以下（或你所在司法管轄區的適用年齡）的兒童。由於不收集任何個人資料，本應用程式對所有年齡層的使用者都是安全的。

## 國際使用者

由於 LinkHQ 不收集任何個人資料，不發生個人資訊的跨境傳輸。逐條連結的中繼資料查詢會存取託管你所儲存連結的那個網站。

## 本政策的變更

如果我們更新本政策，修訂版本會連同新的生效日期發布於此。更新後繼續使用本應用程式即表示接受修訂後的政策。
