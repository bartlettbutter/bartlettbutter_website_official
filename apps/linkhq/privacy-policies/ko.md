**시행일:** 2026년 3월 3일

LinkHQ(“본 앱”)는 iPhone과 iPad를 위한 무료, 기기 전용 링크 아카이브입니다. 개인정보 보호는 본 앱을 만든 방식의 중심에 있습니다. 이 방침은 LinkHQ를 사용할 때 어떤 데이터가 관여하는지, 그리고 더 중요하게는 어떤 데이터가 관여하지 않는지를 정확히 설명합니다.

## 짧은 요약

| 질문 | 답변 |
|----------|--------|
| 개인정보를 수집하나요? | 아니요 |
| 내 라이브러리가 서버로 전송되나요? | 아니요 |
| 계정이나 로그인이 있나요? | 아니요 |
| 추적이나 분석이 있나요? | 아니요 |
| 광고가 있나요? | 아니요 |
| 내 데이터가 판매되거나 공유되나요? | 아니요 |
| 앱이 어린이에게 안전한가요? | 예 |

당신이 저장한 링크와 그 제목, 메모, 태그, 키워드는 모두 당신의 기기에 머뭅니다. 우리는 당신의 데이터를 받는 어떤 서버도 운영하지 않습니다. LinkHQ가 네트워크를 사용하는 유일한 때는 아래에 설명하듯 링크 자신의 메타데이터를 조회할 때입니다.

## 어떤 데이터가 수집되나요

**없습니다.** LinkHQ에는 사용자 계정도, 분석 플랫폼도, 광고 SDK도, 어떤 종류의 추적 장치도 없습니다. 우리는 개인정보를 수집하지도, 저장하지도, 전송하지도 않습니다.

## 앱이 데이터를 기기에서 사용하는 방식

### 저장한 링크

당신이 저장한 링크는 제목, 메모, 태그, 키워드, 출처, 즐겨찾기, 열람 상태와 함께 당신의 기기에만, 공유 앱 컨테이너에 저장되어, 본체 앱과 공유 확장이 하나의 진실 소스를 읽도록 합니다. 이것들은 절대 업로드되지 않습니다.

### 공유 시트에서의 캡처

링크를 LinkHQ로 공유하면, 공유 확장이 공유된 URL이나 공유된 텍스트 안의 링크를 읽어 저장할 수 있게 합니다. 이는 당신의 기기에서 일어납니다. 그 공유에 관한 어떤 것도 우리가 통제하는 어떤 서버로 전송되지 않습니다.

### 기기에서의 키워드 추출

링크를 저장할 때 내용을 설명하는 키워드 몇 개가 당신의 기기에서 추출되어 검색과 필터링에 쓰입니다. 이는 Apple의 기기 내 자연어 프레임워크를 사용해 로컬에서 실행됩니다. 이를 위해 어떤 텍스트도 어디로도 전송되지 않습니다.

## 유일한 네트워크 사용: 링크별 메타데이터 조회

벌거벗은 URL 대신 링크의 실제 제목과 미리보기 이미지를 보여주기 위해, LinkHQ는 링크를 저장할 때 링크별 메타데이터 조회를 수행하고, 조회가 끝나기 전에 저장된 링크를 채우기 위해 앱에서 한 번 더 수행하기도 합니다.

- 요청은 **각 링크 자신의 사이트**, 또는 **그 플랫폼의 oEmbed 엔드포인트**(예: YouTube, TikTok, X)로 가며, 당신의 브라우저가 그 링크에 대해 도달할 것과 같은 목적지입니다.
- 제목, 설명, 사이트 키워드, 미리보기 이미지 URL만 읽습니다. 이미지 URL만 저장하고 이미지 자체는 절대 저장하지 않으며, 미리보기 이미지는 표시될 때 사이트에서 불러옵니다.
- 이러한 요청은 우리가 운영하는 어떤 서버로도 전송되지 않으며, 계정이나 식별자를 담지 않습니다. 애초에 존재하지 않기 때문입니다.
- **당신의 라이브러리는 절대 업로드되지 않습니다.** 조회는 단일 링크의 공개 페이지에 관한 것이지 당신의 모음에 관한 것이 아닙니다.

사이트에 도달할 수 없는 조회는, 예컨대 오프라인일 때, 제목이나 썸네일을 다음 실행에서 채우도록 남겨둘 뿐입니다.

## 권한

LinkHQ는 어떤 민감한 기기 권한도 요청하지 않습니다.

| 권한 | 상태 |
|------------|--------|
| **마이크** | 요청하지 않음 |
| **카메라** | 요청하지 않음 |
| **연락처** | 요청하지 않음 |
| **사진** | 요청하지 않음 |
| **건강 데이터** | 요청하지 않음 |
| **위치** | 요청하지 않음 |

공유 시트에서 링크를 저장하고 출처에서 다시 여는 데는 이러한 권한이 전혀 필요하지 않습니다.

## 제3자 서비스

LinkHQ는 어떤 제3자 분석, 광고, 추적 서비스도 통합하지 않습니다. 메타데이터 조회는 각 링크 자신의 사이트나 그 플랫폼의 공개 oEmbed 엔드포인트에 직접 연결하며, 키워드 추출은 당신의 기기에서 운영체제의 일부로 실행되는 Apple의 기기 내 프레임워크를 사용합니다.

## 데이터 공유

우리는 당신의 데이터를 누구에게도 판매, 임대, 라이선스하거나 공유하지 않습니다. LinkHQ는 당신의 라이브러리, 메모, 태그, 키워드를 전송하는 어떤 네트워크 트래픽도 생성하지 않습니다.

## 데이터 보관 및 삭제

우리는 서버에 어떤 데이터도 저장하지 않으므로 우리 쪽에서 보관하거나 삭제할 것이 없습니다. 당신의 기기에 있는 모든 것, 저장한 링크와 그 모든 세부는, 앱을 삭제하는 순간 제거됩니다. 설정에는 라이브러리를 그 자리에서 비우는 모두 삭제 동작도 있습니다.

## 당신의 권리

우리가 아무것도 수집하지 않으므로 우리 쪽에서 접근, 정정, 이동, 삭제할 개인정보가 없습니다. 앱을 관리하거나 제거함으로써 로컬에 저장된 모든 것을 당신이 완전히 통제합니다.

## 어린이 개인정보

LinkHQ는 13세 미만(또는 당신의 관할에서 적용되는 연령)의 어린이를 포함해 누구에게서도 정보를 수집하지 않습니다. 어떤 개인정보도 모으지 않으므로 본 앱은 모든 연령의 사용자에게 안전합니다.

## 국제 사용자

LinkHQ는 개인정보를 수집하지 않으므로 개인정보의 국경 간 이전이 발생하지 않습니다. 링크별 메타데이터 조회는 당신이 저장한 링크를 호스팅하는 사이트에 도달합니다.
