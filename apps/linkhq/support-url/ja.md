# どんなことでお手伝いできますか？

LinkHQ を存分に活用していただきたいと考えています。思ったように動かないことや疑問があれば、たいていは下に答えがあります。見つからなければ、お問い合わせください。お手伝いします。

## はじめに

### アプリの設定はどうしますか？

LinkHQ を開くだけです。アカウントも登録も不要です。歓迎画面が短い 3 つの手順でしくみを説明し、ライブラリに入ればすぐにリンクの保存を始められます。

### リンクはどう保存しますか？

ほかのアプリでとっておきたいものを見つけたら、「共有」をタップし、共有シートで LinkHQ を選びます。友だちに送るのと同じです。必要ならタイトルを調整し、ソースを選び、メモとタグを追加して Save をタップします。アプリの + ボタンから Add Link でリンクを貼り付けることもできます。

### リンクを保存すると何が起きますか？

LinkHQ は動画・投稿・ページの本当のタイトルとプレビュー画像を入れ、いくつかのキーワードを選び、リンクをトピックに振り分けます。タイトルをすでに編集していれば、LinkHQ はあなたのタイトルを残します。オフラインで保存したリンクは、次に接続した状態でアプリを開いたときに詳細が入ります。

### リンクをどう見つけ直しますか？

Library または Favorites のリスト上部から検索します。タイトル、URL、メモ、タグ、キーワードを対象に、入力中に一致するキーワードを候補として出し、大文字・小文字やアクセントの違いは気にしません。Categories タブを開いて、トピック、ソース、タグ、キーワードで見渡し、さらにお気に入り、未開封、カテゴリ、ソース、キーワードでリストを絞り込むこともできます。

### リンクを元の場所でどう開き直しますか？

リンクを開いて Open Original をタップするか、行を Open までスワイプします。アプリがインストールされていれば、動画や投稿はそのアプリで開きます。YouTube のリンクなら YouTube、RedNote のリンクならノートを RedNote で開きます。対応アプリがないリンクはブラウザで開きます。開いたリンクは開封済みにもなります。

## よくある質問

### LinkHQ は無料ですか？

はい。LinkHQ は無料でダウンロード・利用でき、広告もアカウントもありません。将来、任意のプレミアム機能を追加する可能性があります。

### LinkHQ はデータを集めますか？

いいえ。アカウントも分析も追跡も広告もありません。ライブラリはデバイスにのみ保存され、アップロードされることはありません。詳しくは[プライバシーポリシー](https://bartlettbutter.com/linkhq/privacy/ja/)全文をご覧ください。

### LinkHQ はリンクをどのようにカテゴリに分けますか？

すべてのリンクは、フード、旅行、テクノロジー、音楽など 16 のトピックのどれかに振り分けられます。Apple Intelligence がオンなら、デバイス上の Apple のモデルが振り分けます。オフなら、リンクのタイトル、タグ、キーワードをもとに LinkHQ が振り分けます。どちらもデバイス上で行われます。カテゴリの下の注記に、どちらで振り分けたかが表示されます。

### リンクのカテゴリは変更できますか？

はい。リンクを開いて別のカテゴリを選んでください。LinkHQ はその選択を守り、そのリンクを振り分け直すことはありません。

### LinkHQ はどのプラットフォームを認識しますか？

LinkHQ は主要な 32 のプラットフォームを認識し、各リンクにそれぞれのアイコンと色を付けます。YouTube、Instagram、TikTok、Facebook、WhatsApp、WeChat、Reddit、X、LinkedIn、Pinterest、Threads、Spotify、Bilibili、RedNote、Weibo、GitHub、Medium、Apple Music、Apple Podcasts などです。ほかのどのサイトのリンクも保存でき、Web としてまとめられます。リンクのソースはいつでも変更できます。

### 未開封のリンクとは何ですか？

まだ LinkHQ から開き直していないリンクには小さな点が付き、Unopened フィルタでまとめて見られます。リンクを開くと開封済みになり、行をスワイプして開封済み・未開封を切り替えることもできます。

### 「Unavailable」とは何ですか？

ライブラリを開くたびに、LinkHQ は保存したリンクがまだあるかを確かめます。コンテンツが削除されたリンクには Unavailable と表示され、Categories でまとめて見られます。すぐに確かめたいときは、リンクの詳細で Check Again をタップします。コンテンツが戻れば表示は消えます。サインインが必要なリンクや、接続できなかったリンクが、それだけの理由で Unavailable になることはありません。

### 重複の警告は何を意味しますか？

すでに保存済みのリンクを共有または追加すると、以前いつ、どんなタイトルで保存したかを LinkHQ が表示します。それでも再保存はできます。警告は判断の手助けにすぎません。

### お気に入りはどう使いますか？

リンクの詳細で Favorite をオンにするか、行をスワイプするとお気に入りに追加されます。お気に入りのリンクには専用の Favorites タブがあります。

### ダークモードで使えますか？

はい。Settings の Appearance で System、Light、Dark から選べます。選んだ設定は共有シートから保存するときにも適用されます。

### LinkHQ は iPad で動きますか？

はい。iPad では、サイドバーがライブラリを状態、トピック、ソース、タグで件数つきで整理し、スペースがあればリンクの詳細がリストの横に開きます。キーボードでは ⌘N でリンクを追加、⌘, で Settings を開けます。

### 大きな文字サイズに対応していますか？

はい。すべての文字はデバイスの文字サイズ設定に従い、アクセシビリティの最大サイズまで対応します。

### LinkHQ を評価するには？

Settings で Rate LinkHQ をタップしてください。App Store の LinkHQ のページが開き、評価と、よろしければレビューを残せます。ありがとうございます。とても励みになります。

### ライブラリをすべて消去するには？

Settings で Delete All Links をタップします。確認すると、保存したすべてのリンクがデバイスから削除されます。この操作は取り消せません。

## 権限

### LinkHQ に特別な権限は必要ですか？

いいえ。LinkHQ はマイク、カメラ、連絡先、写真、ヘルスケアデータ、位置情報へのアクセスを求めません。共有シートからのリンク保存や、元の場所での開き直しにこれらの権限は不要です。

### LinkHQ はなぜネットワークを使うのですか？

保存したリンクの情報を調べるためだけです。リンクのタイトルとプレビューを表示し、まだ閲覧できるかを確かめるために、LinkHQ はブラウザと同じリクエストでリンク先のサイト自体に問い合わせ、そのサイトが示す場所からプレビュー画像を読み込みます。キーワードとトピックの振り分けはデバイス上で行われます。ライブラリそのものがアップロードされることはありません。

## トラブルシューティング

### リンクに本当のタイトルが付かなかった

サインインしないと内容を表示しないサイトでは、LinkHQ はリンクと一緒に共有されたテキストしか使えません。また手動で貼り付けたリンクは、編集するまで Web アドレスがタイトルのままになります。問い合わせ回数を制限しているサイトもあります。LinkHQ は次にアプリを開いたときに再試行するので、足りないタイトルは自然に埋まることがよくあります。タイトルはいつでも自分で編集できます。

### 保存したリンクがすぐ出てこない

LinkHQ がバックグラウンドで開いている間に共有シートから保存したリンクは、アプリを閉じて開き直すまで表示されないことがあります。

### Open Original がアプリでなくブラウザを開いた

リンクがアプリで開くのは、そのアプリがインストールされていて、その種類のリンクを開くことに対応している場合だけです。WeChat の記事など、常にブラウザで開くリンクもあります。それ以外の場合は、アプリがインストールされ最新になっているか確認してください。

### サムネイルが出ない

Instagram や TikTok のように有効期限のあるプレビュー画像を使うプラットフォームや、サインインしないとプレビューを出さないプラットフォームがあり、そうしたリンクにはプラットフォームのアイコンが表示されます。リンクの保存や開き直しには影響しません。

### 短縮リンクの重複が見つからなかった

短縮リンク（bit.ly や共有ボタンのものなど）は、LinkHQ が調べた後で、その行き先のリンクと照合されます。接続した状態でアプリを開くと、その機会ができます。

### アプリがクラッシュする

App Store の最新バージョンを使っているか確認し、デバイスを再起動してください。それでもクラッシュが続く場合は、調査できるよう端末の機種と iOS のバージョンを添えてメールでお知らせください。
