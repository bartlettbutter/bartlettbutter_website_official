**生效日期：** 2026年11月8日

Huepick是一款免費的iOS應用程式，用於從照片中提取顏色、構建調色盤，以及使用創意工具轉換影象。本政策以通俗易懂的方式說明我們如何處理您的資訊。

## 簡要版本

| 問題 | 回答 |
|------|------|
| 你們收集個人資料嗎？ | 否 |
| 我的照片會離開我的裝置嗎？ | 否 |
| 有賬戶或登入嗎？ | 否 |
| 有追蹤或分析嗎？ | 否 |
| 有廣告嗎？ | 否 |
| 我的資料會被出售或共享嗎？ | 否 |
| 兒童可以安全使用該應用嗎？ | 是 |

Huepick完全離線運作，不會發出任何網路請求。除非您選擇分享某個創作，否則沒有任何內容會離開您的裝置。

## 我們收集的資料

**無。** 我們不收集、儲存或傳輸任何型別的個人資訊。沒有使用者賬戶，也沒有分析。

## 您的照片

當您拍攝或選擇照片時，所有處理（包括顏色提取、調色盤生成和創意效果）都在您的裝置上本地進行。您的照片永遠不會被髮送到任何地方。

## 照片位置資料

您的照片的後設資料中可能嵌入了GPS座標。Huepick不會使用這些位置資料，也絕不會將其傳送到任何地方。

## 儲存的創作

您從Playground儲存的創作都儲存在您的裝置本地。只有在您選擇分享時，它們才會離開您的裝置。

## 第三方服務

無。Huepick不使用任何第三方服務、SDK或分析工具。

## 資料共享

我們不向任何人出售、共享或出租您的資料。沒有資料可供共享。

## 許可權

| 許可權 | 為何需要 | 是否必需？ |
|------|---------|-----------|
| 相機 | 拍攝照片以提取顏色 | 可選：您可以使用照片庫 |
| 照片庫 | 將處理後的影像儲存到您的照片庫 | 可選 |

選擇現有照片時，Huepick使用iOS標準照片選擇器，只會分享您選擇的照片。Huepick不會要求存取您的位置。

## 刪除您的資料

由於我們不在伺服器上儲存任何內容，因此我們這邊沒有需要刪除的內容。儲存在您裝置上的任何創作都可以在應用內單獨刪除，或透過解除安裝Huepick完全移除。

## 您的權利

由於我們不收集個人資料，因此我們沒有任何內容可供您訪問、更正或匯出。您對自己裝置上本地儲存的一切擁有完全控制權。

## 兒童

Huepick不從任何使用者收集任何資訊，包括13歲以下的兒童（或您所在司法管轄區適用的年齡）。本應用對所有年齡段都是安全的。

## 國際使用者

由於Huepick不收集個人資料，也不發出任何網路請求，因此不會發生個人資訊的跨境傳輸。

## 本政策的變更

如果本政策發生變更，更新後的版本將在此處釋出，並附有新的生效日期。更新後繼續使用該應用即表示接受修訂後的政策。

## 疑問

如果您對隱私或本政策有任何疑問，請傳送電子郵件至 [contact@bartlettbutter.com](mailto:contact@bartlettbutter.com)。
