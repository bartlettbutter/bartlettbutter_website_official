**Data de vigência:** 8 de julho de 2026

FormulaLens é um aplicativo iOS gratuito que ajuda você a entender listas de ingredientes cosméticos ao escaneá-las e classificá-las no seu dispositivo. Construímos este aplicativo com uma filosofia de privacidade em primeiro lugar: não coletamos seus dados porque não precisamos deles.

## Versão Resumida

| Pergunta | Resposta |
|----------|----------|
| Vocês coletam dados pessoais? | Não |
| Minhas fotos saem do meu dispositivo? | Não |
| Há contas ou logins? | Não |
| Há rastreamento ou análises? | Não |
| Há anúncios? | Não |
| Meus dados são vendidos ou compartilhados? | Não |
| O aplicativo é seguro para crianças? | Sim |

## O Que Coletamos

**Nada.** O FormulaLens não coleta, armazena nem transmite nenhuma informação pessoal. Não há contas de usuário, frameworks de análise, SDKs de publicidade nem ferramentas de rastreamento de terceiros incorporadas ao aplicativo.

## Como suas Fotos São Usadas

Você concede acesso à câmera ou à biblioteca de fotos para que o FormulaLens possa ler as listas de ingredientes. Veja o que acontece com essas fotos:

- As fotos são processadas **inteiramente no seu dispositivo** usando a tecnologia de reconhecimento de texto integrada da Apple
- As fotos **nunca são enviadas** para nenhum servidor — nem o nosso nem o de mais ninguém
- As fotos **não são armazenadas** pelo aplicativo além da sessão de análise ativa (a menos que você salve explicitamente um resultado)

## Como Funciona a Análise

Todo o processamento é local:

- **Extração de texto** — realizada no dispositivo pelos frameworks integrados do sistema operacional
- **Identificação de ingredientes** — comparada com um banco de dados incluído dentro do aplicativo
- **Comparações** — calculadas na memória do seu dispositivo

Nenhuma conexão com a internet é necessária. Nenhum dado sai do seu dispositivo durante qualquer uma dessas operações.

## O Que É Armazenado Localmente

Se você optar por salvar uma análise, os resultados são armazenados apenas no seu dispositivo:

- Os nomes dos ingredientes e suas classificações
- Seu rótulo de produto personalizado
- A categoria de produto que você selecionou

Esses dados residem exclusivamente no seu dispositivo e nunca são transmitidos para lugar algum. Eles são excluídos permanentemente quando você desinstala o aplicativo, ou você pode remover itens individuais a qualquer momento dentro do aplicativo.

## Solicitações de Rede

O FormulaLens faz **zero solicitações de rede** durante o uso normal. Nenhuma API é contatada, nenhuma telemetria é enviada e não há transferências de dados em segundo plano.

## Serviços de Terceiros

Nenhum. O FormulaLens não integra nenhum SDK de terceiros, serviço de análise, relator de falhas ou rede de publicidade.

## Compartilhamento de Dados

Não vendemos, alugamos, licenciamos nem compartilhamos dados de usuário com nenhum terceiro. Não há dados de usuário em nossa posse para compartilhar.

## Permissões

| Permissão | Finalidade | Obrigatória? |
|-----------|------------|--------------|
| Câmera | Fotografar listas de ingredientes para escanear | Opcional |
| Biblioteca de Fotos | Selecionar fotos existentes para escanear | Opcional |

O FormulaLens **não** solicita acesso a: localização, contatos, microfone, Bluetooth, dados de saúde, Transparência de Rastreamento de Apps (ATT), notificações push ou qualquer outra permissão sensível do sistema.

## Retenção e Exclusão de Dados

Não operamos servidores nem mantemos bancos de dados de usuários. Todos os dados existem apenas no seu dispositivo. Para excluí-los:

- **Itens individuais** — deslize para excluir dentro do aplicativo
- **Todos os dados** — desinstale o FormulaLens do seu dispositivo

## Seus Direitos

Como não mantemos nenhum dado pessoal em nenhum servidor, não há nada para fornecermos, corrigirmos, transferirmos ou excluirmos. Você tem propriedade e controle totais de tudo o que é armazenado localmente no seu dispositivo.

## Privacidade das Crianças

O FormulaLens não coleta dados de nenhum usuário, independentemente da idade. O aplicativo é seguro para crianças e está em conformidade com a COPPA e as regulamentações de privacidade infantil aplicáveis na sua jurisdição.

## Usuários Internacionais

Como o FormulaLens não coleta dados pessoais e não faz solicitações de rede, não ocorre nenhuma transferência transfronteiriça de dados. O aplicativo funciona da mesma forma independentemente da sua localização.

## Alterações a Esta Política

Se atualizarmos esta política, a versão revisada será publicada aqui com uma nova data de vigência. O uso continuado do aplicativo após uma atualização constitui aceitação da política revisada.
