**発効日:** 2026年10月18日

EarnCall は Bartlett Butter LLC（「当社」）が提供します。EarnCall は、企業の決算、財務スナップショット、四半期トレンド、決算コールのハイライト、今後の決算カレンダーの追跡を助けます。当社はプライバシーを最優先に構築しました。必要がないため、あなたのデータを収集しません。

## 要点

| 質問 | 回答 |
|------|------|
| 個人データを収集しますか？ | いいえ |
| アカウントやログインはありますか？ | いいえ |
| トラッキングや分析はありますか？ | いいえ |
| 広告はありますか？ | いいえ |
| 私のデータは販売・共有されますか？ | いいえ |
| 子どもにとって安全ですか？ | はい |

EarnCall にはアカウントもサインアップもありません。個人データを収集・販売・共有せず、分析や広告も含みません。唯一のネットワーク通信は、公開市場データへの外向きリクエストです。

## 当社が収集するもの

個人的なものは何もありません。EarnCall にはアカウントシステムもサインアップもなく、分析や広告の SDK もありません。あなたのプロファイルを作成せず、あなたに関する情報を受け取るサーバーもありません。

## データの流れ

EarnCall はアプリの数字を本物にするため、**公開市場データ**を取得します。これはあなたに関する何かのアップロードではなく、公開財務情報への外向きリクエストです。

- **Yahoo Finance**: 企業財務、日次価格、決算日、EPS 実績対コンセンサス。
- **SEC EDGAR**: 公開提出書類からの過去の決算発表日。
- **Finnhub**: アナリストセンチメントと決算カレンダー。
- **アプリ自身のトランスクリプトプロキシ**（データ提供元キーをサーバー側で保持する Cloudflare Worker）: Alpha Vantage からの決算コールのトランスクリプト。

これらのリクエストはティッカーと日付を送信し、個人情報は送りません。アカウント、ユーザー識別子、あなたに関する何も含まれず、これらのサービスはあなたを特定するものを一切受け取りません。

## 端末内での要約

決算コールの要点、ハイライト、ガイダンス、成長ドライバー、リスクは、対応端末では Apple の Foundation Models（Apple Intelligence）を使って**あなたの端末上で**生成されます。非対応端末では代わりに、最も関連性の高いトランスクリプト文が端末内で選ばれます。この要約に関わるものは端末から出ません。

## 端末内に保存されるもの

次回起動時にすぐ何かを表示できるよう、EarnCall は最後に取得に成功した企業データと決算スケジュールをファイルとして端末上にキャッシュします。このキャッシュは端末上のみに存在し、どこにも送信されず、アプリを削除すると消去されます。

## 権限

EarnCall は**システム権限を一切要求しません**。カメラ、位置情報、連絡先、マイク、写真のいずれも要求しません。アプリはネットワーク経由で公開市場データへの通常の外向きリクエストを行いますが、iOS は通常の外向き接続に対して許可を求めません。

| 権限 | 要求しますか？ |
|------|---------------|
| カメラ | いいえ |
| 位置情報 | いいえ |
| 連絡先 | いいえ |
| マイク | いいえ |
| 写真ライブラリ | いいえ |
| App Tracking Transparency（ATT） | いいえ |

## 当社が行わないこと

- アカウントもサインアップもなし。
- 分析、広告、トラッキングの SDK なし。
- アプリやウェブサイトをまたぐトラッキングなし。
- 第三者へのデータの販売や共有なし。

## 投資助言ではありません

EarnCall は情報提供のみを目的とし、投資助言ではありません。データは遅延または不完全な場合があります。投資判断の前に必ずご自身で調べてください。

## あなたの権利

当社はいかなるサーバーにも個人データを保持していないため、提供・訂正・移転・削除するものはありません。端末上にローカルにキャッシュされたすべてについて、あなたが完全な所有権と管理権を持ちます。

## 子どものプライバシー

EarnCall は13歳未満の子どもを対象としておらず、子どもを含め誰からも故意に情報を収集しません。アプリは子どもにとって安全であり、あなたの管轄で適用される子どものプライバシー規制を遵守します。

## 国際的な利用者

EarnCall は個人データを収集せず、個人情報をどこにも送信しません。唯一のネットワーク通信は公開市場データへの外向きリクエストのため、あなたの個人データの越境移転は発生しません。アプリは所在地にかかわらず同じように動作します。
