**시행일:** 2026년 9월 27일

Sayminder("본 앱")는 iPhone 및 iPad를 위한 무료 음성 우선 리마인더 앱입니다. 개인정보 보호는 본 앱을 만든 방식의 핵심입니다. 본 방침은 Sayminder를 사용할 때 어떤 데이터가 관련되는지, 그리고 더 중요하게는 어떤 데이터가 관련되지 않는지를 정확히 설명합니다.

## 요약 버전

| 질문 | 답변 |
|----------|--------|
| 개인정보를 수집하나요? | 아니요 |
| 제 음성이나 전사 내용이 서버로 전송되나요? | 아니요 |
| 계정이나 로그인이 있나요? | 아니요 |
| 추적이나 분석이 있나요? | 아니요 |
| 광고가 있나요? | 아니요 |
| 제 데이터가 판매되거나 공유되나요? | 아니요 |
| 이 앱은 어린이에게 안전한가요? | 예 |

리마인더, 사용자가 말한 텍스트, 일정, 텍스트 음성 변환은 모두 사용자 기기에 남습니다. 저희는 사용자의 데이터를 수신하는 어떠한 서버도 운영하지 않습니다.

## 수집되는 데이터

**없음.** Sayminder에는 사용자 계정, 분석 플랫폼, 광고 SDK, 그리고 어떤 종류의 추적 메커니즘도 없습니다. 저희는 개인정보를 수집, 저장 또는 전송하지 않습니다.

## 앱이 데이터를 로컬에서 사용하는 방식

### 마이크 및 음성 인식

마이크 및 음성 인식 권한을 부여하면, 음성이 리마인더가 될 수 있도록 전사됩니다. 사용자의 언어 모델을 사용할 수 있는 경우 인식은 Apple의 기기 내 음성 인식을 우선적으로 사용하며, 해당 모델을 사용할 수 없는 경우에는 시스템의 기본 음성 인식 경로를 사용하여 오디오를 전사합니다. Sayminder는 사용자의 오디오나 전사 내용을 저희가 관리하는 어떠한 서버로도 전송하지 않습니다.

### 리마인더 및 메모

사용자가 만든 리마인더(제목, 메모, 시간, 반복 설정, 원본 음성 전사)는 사용자 기기에만 저장되며, 앱과 위젯, Siri/단축어 인텐트가 단일한 신뢰 소스를 읽을 수 있도록 공유 앱 컨테이너에 보관됩니다. 이 데이터는 절대 업로드되지 않습니다.

### 캘린더(선택 사항, 읽기 전용)

**캘린더 일정 표시**를 켜면, 앱이 시스템 캘린더의 일정을 읽어 사용자의 리마인더와 함께 표시합니다. 이 접근 권한은 읽기 전용입니다. Sayminder는 절대 캘린더 일정을 생성, 편집 또는 삭제하지 않으며, 일정은 일과표를 표시하기 위해 사용자 기기에서만 읽힙니다. 이 계층은 사용자가 활성화할 때까지 꺼져 있습니다.

### 일정 관리 및 텍스트 음성 변환

알람, 알림, 음성 읽어주기는 모두 사용자 기기에서 운영체제의 프레임워크에 의해 처리됩니다. 어떠한 일정 데이터나 읽어주는 텍스트도 어디로도 전송되지 않습니다.

## 권한

Sayminder는 다음 권한을 요청합니다.

| 권한 | 목적 |
|------------|---------|
| **마이크** | 리마인더를 만들 수 있도록 음성을 캡처 |
| **음성 인식** | 음성을 리마인더 텍스트로 전사 |
| **알림 / 알람** | 리마인더 시간에 사용자에게 알림 |
| **캘린더(읽기 전용, 선택 사항)** | 사용자가 활성화한 경우에만 기존 일정을 리마인더와 함께 표시 |

이 외의 다른 권한은 요청하지 않습니다. 카메라, 연락처, 사진, 건강 데이터, 위치 정보는 요청하지 않습니다.

## 제3자 서비스

Sayminder는 어떠한 제3자 분석, 광고 또는 추적 서비스도 통합하지 않습니다. 음성 인식은 Apple의 기기 내 및 시스템 음성 인식 프레임워크를 사용하고, 일정 관리와 텍스트 음성 변환은 Apple의 시스템 프레임워크를 사용합니다. 이들은 사용자 기기에서 운영체제의 일부로 실행됩니다.

## 데이터 공유

저희는 사용자의 데이터를 누구에게도 판매, 대여, 라이선스 제공 또는 공유하지 않습니다. Sayminder는 사용자의 리마인더, 음성, 전사 내용 또는 캘린더 데이터를 전송하는 네트워크 트래픽을 발생시키지 않습니다.

## 데이터 보관 및 삭제

저희는 서버에 어떠한 데이터도 저장하지 않으므로 보관하거나 삭제할 것이 없습니다. 사용자 기기의 모든 정보(리마인더, 메모, 전사 내용, 환경설정)는 앱을 삭제하는 즉시 제거됩니다.

## 사용자의 권리

저희는 아무것도 수집하지 않으므로, 저희 측에서 접근, 정정, 이동 또는 삭제할 개인정보가 없습니다. 앱을 관리하거나 제거함으로써 로컬에 저장된 모든 것을 완전히 통제할 수 있습니다.

## 아동의 개인정보

Sayminder는 13세 미만 아동(또는 사용자의 관할권에서 적용되는 연령)을 포함하여 그 누구로부터도 정보를 수집하지 않습니다. 개인정보가 전혀 수집되지 않으므로, 본 앱은 모든 연령의 사용자에게 안전합니다.

## 국제 사용자

Sayminder는 개인정보를 전혀 수집하지 않으므로, 개인정보의 국경 간 이전이 발생하지 않습니다.
