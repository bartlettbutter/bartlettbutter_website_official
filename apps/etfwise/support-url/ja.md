# どのようなお手伝いができますか？

私たちはあなたがETFWiseを最大限に活用できるようお手伝いします。以下の回答をご覧いただくか、必要なものが見つからない場合は直接お問い合わせください。

## はじめに

### 毎日の推奨はどのように機能しますか？

毎日、ETFWiseはリアルタイムの市場データに基づいて、7つのカテゴリー（主要指数、セクター、債券・確定利付、インターナショナル、コモディティ、テーマ、配当）にわたってトップETFを選定します。リストは終日固定され、ビューが安定して保たれる一方、価格とセンチメントは5分ごとに自動的に更新されます。サブカテゴリーを探索するには、任意のセクションで「もっと見る」をタップしてください。

### インターネット接続は必要ですか？

はい、リアルタイム価格、ニュース、センチメント、ファンドデータには必要です。強気・リスクシナリオの分析は、すでに画面に表示されているデータからあなたのデバイス上で即座に生成されるため、追加の接続は必要ありません。

### ETFWiseはいくらですか？

ETFWiseはApp Storeから無料でダウンロードできます。サブスクリプションや広告はありません。

## よくある質問

### 7つのETFカテゴリーとは何ですか？

| カテゴリー | 対象内容 |
|---|---|
| 主要指数 | S&P 500、ナスダック100、ラッセル2000、ダウ・ジョーンズ、トータルマーケット |
| セクター | テクノロジー、ヘルスケア、エネルギー、金融など |
| 債券・確定利付 | 国債、社債、ハイイールド、TIPS、地方債 |
| インターナショナル | 先進国市場、新興国市場、単一国ETF |
| コモディティ | 金、銀、石油、農業、広範なコモディティバスケット |
| テーマ | AIとロボティクス、クリーンエネルギー、サイバーセキュリティ、クラウド、EV |
| 配当 | 高利回り、配当成長、アリストクラット、インカム戦略 |

### 強気・リスクシナリオはどのように生成されますか？

ETFWiseは、各強気シナリオとリスクシナリオを、そのETFについてすでに表示されている実データ（価格、リターン、センチメント、経費率など）からあなたのデバイス上で構築します。生成は即座に行われ、ダウンロードやアカウントは不要で、外部サーバーには何も送信されません。

### ニュースセンチメントはどのように機能しますか？

アプリは各ETFの最近のニュース記事（7日間の期間）を分析し、肯定的または否定的なトーンをスコア化します。結果は、弱気、ネガティブ、ニュートラル、ポジティブ、または強気として表示されます。スコアの横に最大3件の最新見出しが表示されます。

### 特定のETFを検索できますか？

はい。検索バーを使って、ティッカーシンボルまたは名前で任意のETFを見つけられます。検索は200以上の厳選されたETFに加え、合計450以上のティッカーの拡張ライブラリをカバーします。

### 私のデータはプライベートですか？

はい。アカウントなし、分析なし、トラッキングなし。金融データプロバイダーに送信されるのはティッカーシンボルのみです。詳細は完全な[プライバシーポリシー](https://www.bartlettbutter.com/etfwise/privacy/)をご覧ください。

### アプリを削除するとどうなりますか？

ETFWiseをアンインストールすると、キャッシュされた推奨や生成された分析を含む、ローカルに保存されたすべてのデータが完全に削除されます。クラウドバックアップがないため、これは元に戻せません。

## トラブルシューティング

### 価格が読み込まれない

デバイスがインターネットに接続されていることを確認してください。価格は5分ごとに自動的に更新されます。更新に失敗した場合は、次のサイクルまたはアプリを再度開いたときに更新されます。

### 「ETFデータを読み込めません」エラー

これは通常、ネットワークリクエストが失敗したことを意味します。インターネット接続を確認し、「再試行」をタップしてください。

### 強気・リスクシナリオが表示されない

強気・リスクシナリオは、ETFの価格、パフォーマンス、センチメントのデータから構築されます。表示されない場合は、その基となるデータの読み込みがまだ完了していません。インターネットに接続されていることを確認してから、ETF詳細ビューを再度開いてください。

### ファンドデータ（保有銘柄、パフォーマンス）が読み込まれない

保有銘柄とパフォーマンスのデータにはインターネット接続が必要です。データの読み込みに失敗した場合は、ETF詳細ビューを閉じて再度開いてみてください。

### アプリがクラッシュまたはフリーズする

App Storeの最新バージョンを実行していることを確認し、アプリを強制終了して再度開いてください。問題が続く場合は、デバイスを再起動してください。それでも解決しない場合は、下記までお問い合わせください。

## 対応環境

ETFWiseはiOS 18.0以降が必要で、iPhoneとiPadの両方で動作します。
